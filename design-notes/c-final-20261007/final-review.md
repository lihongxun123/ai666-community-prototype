# C端最终检查 · 2026-10-07

当前研究室C端原型已完成本轮最终检查，发现的明确页面、交互和需求差异已修正。范围为PC与移动端；跨产品专项按用户决定暂缓。本轮未提交、推送或发布。

## 改动页面

| 页面 | 本轮修正 |
|---|---|
| 首页（PC） | 接入阅读台的空态、加载、失败、加载更多失败、封面失败状态；失败可重试，已加载的专题保留。 |
| 作品详情（移动端） | 评论不再默认以浮层覆盖详情；点击评论后打开，关闭后回到作品。 |
| 作品详情（双端） | 后台维护作品的参考图片接入统一媒体预览。 |
| AI应用列表（移动端） | 同组应用按发布时间和ID稳定排序，与现有口径一致。 |
| AI应用详情（移动端） | 移除旧附件内容展示路径，与PC及已确认范围一致。 |
| 圈子、帖子列表、帖子详情、发帖/草稿 | 圈子关系使用稳定ID，改名不丢关联；保留旧示例名称兼容；移出圈子同时清除关联。 |
| 圈子推荐帖子（PC） | 移除固定示例优先，按发布时间排序。 |
| 兑换记录、兑换成功（移动端） | 卡密卡片内按钮统一为“复制”。 |
| 产品方案、页面需求、模块流程及共用规则 | 同步爆款唯一来源、取消独立帖子推荐编排/应用排序、圈子启停和新增活动任务口径。 |

圈子关联修正同步了原型中B端选圈与公开快照的关联字段，未改真实业务仓库，也未扩展跨产品互通。

## 检查结果

- 当前注册37个页面标识；PC30个、移动端32个独立评审入口，设备合并路由有效，37项页面需求与产品方案覆盖完整。
- 62个正常入口完成DOM、可见图片和页面宽度检查：未发现横向溢出或可见缺图。PC按1280×720、移动端按390×844检查；视觉细节采用代表页面截图复核，并非所有屏幕尺寸逐像素验收。
- 24个双端状态样本与4个PC首页修复后状态完成检查。覆盖空态、加载失败、内容下架、提交失败、积分不足及首页加载/封面失败。
- 浏览器操作复核：手机作品评论打开/关闭、参考图预览、帖子正文必填、首页失败重试、账户快捷菜单、积分不足生成按钮禁用、帖子图片切换/关闭。
- 独立复核已完成；发现的圈子名称关联、应用附件残留和首页错误态误隐藏专题已修正。圈子连续改名、公开快照读取与旧样本兼容另有运行断言检查。
- TypeScript与完整Node构建通过；页面需求登记校验通过。相关文件lint仍包含既有React effect、可访问性及类型格式化问题，未将本次结果描述为全站lint无错误。

## 验证路径

1. 手机打开作品详情，确认没有评论浮层遮挡；点击评论、关闭，再点击参考图。[作品详情](02-work-mobile.png)、[参考图预览](03-media-mobile.png)。
2. PC首页切到加载失败，专题仍显示；重试回到作品流。[首页状态](05-home-error-pc.png)。
3. PC打开帖子图片，点击下一项、关闭，检查箭头与关闭图标。[媒体预览](06-post-media-pc.png)。
4. AIGC积分不足时生成按钮禁用，不弹积分不足对话框。[生成入口](04-generation-pc.png)。
