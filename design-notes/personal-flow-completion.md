- 积分中心与商城继续共用 `storage.ts` 的演示余额和商城兑换记录；多条生成任务按 ID 保留，积分明细逐条区分占用、结算和释放。签到和邀请页去掉虚构邀请人和固定到账奖励。会员独立页已按本轮决定移除。
- 新手任务“完善资料”通向资料编辑。活动详情、发布表单、投稿记录之间保留活动编码和名称。
- B 端活动状态按六个既有 code 回写到 C：已结束、已停用、未解锁均禁止新参与和投稿，已有投稿仍可查看。B 端同 SKU 的商品停用、库存和积分条件回写 C 商城；兑换前重新校验并在成功后扣库存。B 投稿的资格、活动评审、奖励结果按同一投稿 ID 回显，且与内容公开审核分开。
- 生成后发布从明确活动参数传递活动身份；普通应用任务清理残留活动。结果页按任务 ID 找回旧生成结果，编辑页只读取本次结果的活动和来源，不串到最新任务。个人生成记录可找回多条任务。
