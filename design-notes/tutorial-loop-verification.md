# 首条联动样本：教程、资源与成果回流

日期：2026-09-25｜状态：首条静态交互样本已制作并走查；全站原型未完成。

预览：`http://127.0.0.1:3000/research-walkthrough/tutorial-loop.html`。

## 如何查看

1. 在后台编辑教程，选择已有资源，保存并提交审核。
2. 使用明确标注的“模拟审核通过”，再由维护者点击“正式发布”。
3. 在顶部切到手机发现，打开教程、目录与资源详情。点击电脑端复用可查看跨设备提示。
4. 通过顶部“PC 承接”继续同一页走查；复制出的本地定向链接也可在桌面宽度直接打开项目模拟页。链接包含样本项目和版本，不是实际 MakeNow 接口。
5. 模拟取得自己的副本，选择已有成果，确认演示账号关联，再回到社区补充、保存、预览与提交。

顶部控制和走查规则属于评审辅助工具。样本为虚构内容，复用研究站图片；没有真实生成结果、真实账号关联或真实发布。页面内存记录随刷新重置，复制链接不会同步当前页的编辑和场景状态。

## 本次实际验证

使用 Codex 内置浏览器操作本地页面，验证了以下样本行为：

| 范围 | 观察结果 |
| --- | --- |
| 教程审核与生效 | 提交后锁定编辑；审核通过仍未公开；正式发布后列表可读 |
| 教程修订 | 保存修改后的标题，公开详情仍保留原标题 |
| 资源状态 | 仅展示、仅查看、允许复用、暂停、下架各自显示对应说明与动作；下架详情不显示封面和正文 |
| 引用失效 | 原教程仍可阅读，引用变为不可访问提示；后台携带失效引用时提交被阻止 |
| 跨设备承接 | 手机显示电脑端说明；带 R-001 / v1 的本地链接在桌面宽度进入指定项目模拟页 |
| 副本边界 | 模拟复制后进入“我的私人副本”；源资源下架不覆盖自己的副本或私人结果 |
| 成果回流 | 首次确认两端演示账号；只回流所选成果，进入私有编辑页；默认不允许再次分享工程仍可提交合法成果 |
| 私有保存与提交 | 保存有独立内存快照和可见状态；预览后显式提交，结果停在待审核 |
| 活动失效 | 保留输入并禁用提交；明确解除关联、重新预览后才可普通提交 |
| 同次回流重复 | 回流同一动作恢复 P-001 待审核记录，不重复建稿 |
| 布局与资源 | 360px 移动宽度及 1440px 桌面宽度检查；所检查页面横向溢出为 0、图片无加载失败；发现并修正返回图标路径和尺寸 |
| 基础检查 | JavaScript 语法检查通过；所观察操作未出现浏览器控制台错误 |

另完成一次独立的需求与代码复核，修正了工程分享许可和成果发布许可混淆、失效资源展示、定向链接、引用复查、私人副本身份及草稿保存状态。独立复核未包含第二次浏览器实测，浏览器走查由主代理完成。
