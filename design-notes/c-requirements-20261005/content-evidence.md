## 保留的重要原规则

- 首页分类只筛选本页入选作品，返回恢复本分类；移除对象不重排其他对象。
- 专题可仅一种类型、少量内容，不凑齐类别；引用不复制内容身份和讨论；目标恢复不自动恢复推荐。
- 应用使用详情不放生成表单，不承诺素材传递、成果回传、自动选中 Agent／Skill 或免费执行；音频无源不放假播放。
- PC 圈子就地展开正文、图和评论，各帖输入独立；分享仍落原帖；退出当前圈子回推荐。
- 圈子关闭、帖子公开、加入关系独立；普通关闭不自动删除合法帖，违规整体限制不能套普通关闭规则。
- 作品提示词展示、复制、同款同源；参考素材不等于成果图；工程撤回只停对应工程入口。
- 官方维护教程不等于官方原创；发布修改不提前露出；无效标识不回落其他正文。
- 搜索不含私人内容和独立资源；默认不预填词、无“全部”结果类；访客记录不持久化。
- 作者普通／官方账号均只作品、帖子；无私人积分、收藏、草稿和活动参与明细。
- 公共 G01/G02/G04/G05/G07/G08 承担重复规则。评论逐条保留、回复绑定、本人编辑不改子回复等由 G04 完整维护，页面仅保留承载和局部阈值差异。

- 需求 B 的 op-topics 仍出现“作品、教程、应用或资源”，B 端也保留 resource 类型；当前 C 已合并资源入口。本稿按 C 新决定落应用／素材，不恢复独立 C 资源详情；B 内部资源对象是否保留不由本稿决定。

- B 原型专题选择器可出现比当前 C 页面更广的对象集合；当前 C 正文仅保留已定义的作品／教程／应用，不据选择器自动扩入帖子或独立资源。
