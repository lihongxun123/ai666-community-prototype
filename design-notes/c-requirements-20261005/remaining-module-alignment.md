# C端剩余模块需求与原型一致性核对

日期：2026-10-05。接续评论、已有作品追加投稿、上下架与兑换异常演示。依据当前页面需求、公共规则及用户已确认决定；只修改研究室原型和文档，不修改真实C/B服务。

## 本轮修正

|模块|发现的不一致|处理|
|---|---|---|
|邀请规则|完整规则仍按首次输入或点击建立关系|统一为首次成功绑定|
|邀请补绑|手机缺入口；PC关系仅存在组件内，返回即丢失|两端共用补绑表单，同一会话保存；自邀与无效码就地反馈；成功禁用重复操作|
|登录邀请|邀请链接带参但登录未带入|恢复invite参数；绑定失败不阻断登录，回来源后给一次反馈|
|关注/粉丝|回关使用独立状态，关注列表和个人数字不同步|复用同一关注关系，个人页及头像菜单统计联动；取消回关不减少粉丝基数|
|粉丝主页|链接用author参数，而作者页读取name|统一目标参数，进入所选作者|
|生成历史与结果|参考图片只有图片，没有预览操作|接入共用媒体预览，关闭返回原记录/结果|
|生成活动|未按生成类型筛活动；PC旧任务标识未完整传递|PC/手机按现有配置过滤，失效关联阻止新生成并要求重选；PC保留活动任务至发布|
|生成时间|无时间的旧记录用当前时间冒充|显示时间未记录；有时间使用北京时间|
|搜索展示|结果无高亮，正文命中看不出原因；PC说明悬停才显示|七类结果普通文字展示、已有可检索摘要截取命中片段；作品结果常显名称与摘要，不改变其他作品流|
|签到/交接资料|签到介绍仍写领取，时区仍标待定；收口报告把已实现项列待确认|改为签到获得积分；时区引用北京时间；旧报告指向本轮记录|

## 核对覆盖与边界

|范围|本轮检查|
|---|---|
|生成、结果、发布|参数与类型、活动来源传递、参考素材预览、已失效活动保留提示；沿用现有发布必填与素材限制|
|搜索、作品卡片|七类入口、匹配与摘要展示、统一详情目标；不接服务端全文索引|
|登录、账号、邀请|原有绑定保护与个人资料路径、邀请参数、补绑、返回来源；身份认证和审核由真实服务负责|
|我的、作者与关系|回关、关注列表、统计及所选作者目标；不修改既定作品/帖子栏目|
|消息、积分、签到|单条/全部已读和来源目标、余额/明细来源、自动发放、签到自然周；消息无目标仅标读规则保留|
|商城、活动与其他列表|沿用上轮已核对的兑换异常、投稿、去重及上下架结果，本轮不重复宣称重新验收全部状态|

## 验证

独立源码复核发现摘要使用归一化偏移直接截原文的问题，已改用组合字素映射。类型检查通过；浏览器验证无效邀请码、PC成功绑定后切手机仍已绑定、历史及结果参考图打开共用预览、粉丝回关后关注数24→25且列表出现同一人、搜索高亮可见。

邀请会话保存不代表跨设备真实存储，演示邀请码不代表真实邀请人身份验证。生成素材、报价、任务费用、计数发奖、消息事件以及搜索索引仍为研发交接。当前未宣称所有37页全部异常状态逐项实测，也未宣称全量lint通过。

本轮不增加新的业务待决策项。后续按真实接口映射和B端配置职责衔接，C端本地原型的最终验收仍需使用正式验收清单。
