| 商城兑换 | 商品/站点、库存、生效范围、价格、权益交付和异常处理 | 确认兑换、结果、历史记录 | 价格变更再次确认；已扣分未交付不报成功；商品停用不删除旧记录；卡密仅对应本人兑换 |
| 账号与关系 | 身份能力、账号限制、绑定状态、治理结果 | 登录、绑定/换绑/解绑、关注/粉丝 | 不可解除唯一可用登录方式；占用账号不覆盖；公开页不暴露绑定资料 |
| 通知与反馈 | 通知类型、业务对象、可读原因与操作结果 | 进入具体对象或获知失效原因 | 失效不跳无关对象；内部审核/风控信息不原样下发为文案 |

## 状态设计的共同要求

每个可处理对象至少在设计说明中回答：谁触发、前置条件、成功后是什么、失败后保留什么、结果未知如何恢复、能否撤销/重试、是否影响已存在记录。无需为每一种情况增加页面；字段提示、按钮状态、同一弹层结果可以承载。

状态图不得只写“待审核→通过→成功”。例如投稿要区分内容审核、是否公开、投稿资格和奖励到账；兑换要区分请求受理、积分结算和权益交付。用户可见文案使用业务语言，后台保留可追溯处理结果。

### 投稿内容下架与奖励

下架保留投稿记录；公开型任务发奖前重校验，无关任务不受影响。恢复沿用原记录重校验，不重复奖励，已结束活动不自动补发。普通下架不自动追扣；违规作弊由后台按规则处理并记录原因、积分流水。


### 列表排序配置

首页爆款作品由后台选择并控制展示顺序，C 端按返回顺序展示，不按点赞、收藏或发布时间自行重排；分类筛选保留相对顺序。现有管理端代码已确认爆款标记维护，尚未找到普通作品独立排序入口，排序配置与返回顺序的映射在 B 端设计时补齐，不能复用模板或广告位排序充当作品排序。

PC 全部应用先展示已配置运营顺序的应用，按配置顺序排列；未配置项排在其后，按首次公开时间倒序。同序或同时间按稳定标识排序，重新上架不重置首次公开时间。精选应用 Banner 使用独立运营选品与顺序，只推荐公开且可用应用，空配置隐藏；手机最新上线继续按首次公开时间倒序，两者不混用。

圈内多条置顶按管理员配置的置顶顺序展示，同序按稳定标识排序；普通帖按首次公开时间倒序，同时间按稳定标识排序。置顶帖不在普通流重复出现，取消置顶回到原首次公开时间对应位置，编辑不刷新位置。


### 搜索推荐与检索联动

热门词、精选专题及精选应用分别维护对象／词条、顺序和启停；无配置隐藏，活动不进入默认推荐。七类结果读取各自有效公开字段，原内容改名、发布、下架或权限变化同步检索有效性，不能另建失去同步的正文副本。检索按search页面的字段与相关性规则执行，逐项核对全文字段、索引延迟及权限过滤；不要求原型实现检索服务。


### 草稿保存与引用保护

同账号跨端恢复已成功保存的字段及上传成功并保存关联的素材；手动草稿最近成功保存起30天，打开不续期。失效素材标记并允许替换，保留其余内容。草稿删除二次确认且无回收站，不连带删除来源作品、生成记录或其他内容使用中的素材。待审、退回稿及生成记录不适用草稿期限；草稿存储与物理素材清理由研发核对实现，不新增运营代编辑用户草稿的权限。


### AIGC生成资产

AIGC生成结果属于用户资产。本期不设置保存到期时间，不增加到期提醒、到期失效或按期限自动清理；手动草稿30天规则不适用于生成结果与生成记录。生成记录本期不支持用户删除，进行中与已结束任务均不提供删除或批量删除入口，不设置删除确认及回收站。保存到草稿、发布作品与生成来源保留关联，草稿到期或删除不连带删除生成资产；既有内容权限和违规治理规则仍分别执行。本期不处理保存期限，不将其宣传为永久存储服务承诺。后台治理不据此获得任意删除资产权限；本轮不新增清理配置。


### 已发布内容删除与引用

本人删除作品／帖子需确认且无回收站；删除后引用方隐藏引用区，不显示失效占位，保留自身正文与讨论。原详情及所属评论不再公开展示，必要参与和奖励记录保留并注明原内容已删除。发奖前校验公开条件，普通删除不自动追回已到账奖励，不删除生成资产。此规则与父评论删除保留回复占位分别处理。


### 个人资料审核沿用现状

不新增个人资料人工审核工作台或逐字段待审版本。昵称／头像变更在整组资料保存时同步机审；当前简介、性别未见机审调用。保存结果与数据库写入一致性另列研发修复项：现有后端先写入后检查，失败未见回滚，不能将页面失败当作资料未变更的证据。


### 邀请码补绑资格

新旧账号未绑定时均可绑定，本期无注册后补绑期限。以首次成功绑定为准，拒绝自邀、无效码和重复绑定，不提供换绑／解绑入口。登录绑定失败不影响登录，既有关系不能被新链接覆盖；关系、阶段资格与奖励到账独立，旧账号补绑不承诺历史行为自动补算或补发。


### 活动与邀请规则调整

活动与邀请规则调整由运营人工控制，沿用现有后台编辑能力，不新增规则版本管理、按用户分组或自动兼容旧规则能力。活动开始后尽量不改奖励、门槛和期限；确需调整，由运营先核对受影响用户并说明变更，已完成任务与待发奖励等特殊情况人工核对处理。保留现有参与记录与积分流水便于核查；不据此新增任意发分、改账权限。此项属于运营操作约束，不增加C端版本选择、自动补算或新弹层。


### 兑换异常处理

已扣未交付且无终局结果显示兑换结果确认中，仅查询原记录；明确失败区分未扣分、积分返还处理中、已返还。长时间无结果通过现有客服入口人工核对，不自动重建订单。商品下架保留成功记录及卡密查看复制；原卡密自身有效期不变。实际履约与账务结果映射交研发，不增加独立工单系统或新改账权限。


### 统一业务时间与字数

业务时间采用北京时间，开始包含、结束不包含，日／月限额按北京时间切换；C端展示与B端配置使用相同口径。文本按用户可感知字符计数，组合表情算1个，内部空格和换行计入，各字段限额不变。前后台与服务端校验需一致，不由浏览器时区或UTF-16长度代替已定规则。


### 原积分过期后的返还

返还沿用原批次到期时间，未过期部分恢复可用，已过期部分不恢复并说明原积分已过期；混合批次分别判断。用户侧区分返还处理中、已返还及恢复可用金额；特殊补偿由运营人工核对，使用既有授权并单独留痕，不新增自动补偿或通过返还续期。具体账务字段、枚举及混合批次数据由研发交接核对。


# C 端公共交互与业务规则

适用 PC 与移动端。页面需求规定业务差异，本节统一重复行为。状态名称描述用户可见含义；接口枚举与未明确参数待服务映射，不由设计或前端自行补值。

## G01 登录、权限与返回

| 场景 | 行为与恢复 |
|---|---|
| 游客浏览公开内容 | 可浏览；关注、收藏、评论、发布、兑换、签到等本人操作先登录 |
| 从业务动作进入登录 | 在当前标签页的可恢复范围内保存来源对象、栏目、滚动及未提交输入；登录成功返回来源，不自动执行发布、兑换或其他原动作；不承诺跨设备或浏览器关闭后恢复未保存输入 |
| 取消登录或登录失败 | 返回原背景，保留输入；失败说明原因，允许重试；不跳到无关首页 |
| 来源内容已失效或权限变化 | 返回后重新判断可访问性；说明不可继续的原因并提供返回，不能沿用登录前权限 |
| 私有数据 | 草稿、生成记录、积分、兑换记录仅本人可见；公开作者页不暴露这些内容及账号绑定资料 |
| 退出或切换账号 | 清除上一账号的私有界面与未提交恢复上下文；不得将原账号输入、搜索记录或余额带给新账号 |

## G02 列表、筛选与返回定位

| 场景 | 行为与恢复 |
|---|---|
| 首次进入 | 使用该页默认栏目与排序；加载中不当成空列表 |
| 切换筛选或搜索词 | 从首批加载，旧条件的晚到结果不能覆盖新条件；清空筛选恢复默认 |
| 滚动续载 | 保留已有卡片；失败在列表末尾重试，不清空已加载内容；无更多时停止请求 |
| 详情返回 | 恢复来源条件、已加载内容与位置；目标失效时移除该项，其他卡片相对顺序不变 |
| 数据去重 | 同一业务对象在同一列表不重复；名称不是去重依据；重新加载不得混入旧筛选结果 |

分页数量和缓存时长由研发确定。推荐、热度、最新及后台排序必须按页面定义区分，不能由前端自行替换。

作品媒体流在同一设备下沿用首页的横纵间距、圆角、标题字号与图片内留白；适用于 AIGC、搜索作品结果、作者作品和活动投稿。列数按内容区域宽度调整，不拉伸图片。专题集合、应用介绍与管理列表按各自信息结构排布，不能将作品流的紧凑间距套到所有卡片。

列表顺序：AIGC 公开流按首次公开时间倒序；PC 应用目录配置项优先、未配置项按首次公开时间倒序；圈内置顶独立排序、普通帖按首次公开时间倒序，取消置顶返回原位置。首页爆款按后台返回顺序，精选应用 Banner 单独编排。并列按稳定标识排序；编辑和重新上架不刷新首次公开时间。

## G03 表单、文件与主动提交

| 场景 | 输入与处理 |
|---|---|
| 必填文本 | 去除首尾空白后校验；全空白视为空。显示字段级原因，不只弹“提交失败” |
| 长度或格式不符 | 使用页面确认的限制；保留输入并定位错误，不静默截断。字符计数统一见下方计数规则，尚未确定的字段限额仍须单独明确 |
| 上传取消、失败、不合规 | 取消不改变原文件；失败保留其他成功文件，允许移除或重试；格式、数量、大小、时长按所选能力的有效限制展示 |
| 上传未完成 | 不把临时预览当成上传成功；依赖该文件的提交不可执行，给出原因 |
| 提交中 | 按钮显示处理中并防重复；不清空输入；切换页或关闭的保留规则由对应编辑页定义 |
| 明确提交失败 | 显示可行动原因，保留可恢复输入；按原对象继续修改，不自动新建副本 |
| 超时或结果未知 | 按 G05 查原请求，不直接当成失败再次提交 |

验证码、绑定方式和手机号按身份服务规则验证；正式能力限制以接口配置为准。

## G04 关注、喜欢、收藏与评论

| 动作 | 成功与异常 |
|---|---|
| 关注、喜欢、收藏 | 状态与数量按最终结果同步；重复点击不重复计数。失败恢复原状态并短提示；不能只改数字不改关系 |
| 发表评论 | 文字去除首尾空白，文字和合格图片至少有一项；文字上限 1000 字符，按用户可感知字符计数。成功追加当前对象评论，失败保留输入 |
| 回复 | 明确“回复谁”，关联原评论身份；取消回复恢复普通评论；展开、收起不丢失输入 |
| 编辑本人评论 | 不提供编辑入口；需要修改时删除后重新发表 |
| 删除本人评论 | 仅本人删除自己的条目，二次确认；父项删除后移除条目且不展示删除占位，保留合法回复，隐藏原文图片，禁止继续回复被删除项；作者不可删除他人评论 |
| 内容失效或评论权限关闭 | 停止提交并解释原因；保留可复制的输入；不把请求发送到其他作品或帖子 |

评论中的审核结果与公开展示以服务端可见性为准，发送成功不等于所有用户立即可见；页面不暴露内部审核命中、风控字段或审核人员信息。

### 评论图片与审核

评论文字与图片均纳入审核。本人删除后，合法回复独立展示，不再挂在已删除内容下。后台屏蔽隐藏原文和图片，保留必要占位与合法回复；本人可见原因，其他人不可见内部审核信息。图片使用共用媒体预览。每条评论或回复最多 1 张图片，支持 JPG、JPEG、PNG、WebP，单张不超过 10MB。允许纯图片提交，文字和图片至少有一项；空白文字不计有效内容。超限或格式错误就地提示，保留已输入文字与合格图片，不静默替换已有图片。JPG 与 JPEG 为同一图片格式的不同扩展名。

## G05 异步结果与结算

| 当前情况 | 用户应看到 | 可执行动作 |
|---|---|---|
| 请求尚未发起 | 可操作的初始状态 | 主动提交 |
| 已受理，处理未结束 | 排队、生成中或处理中，按真实业务选词 | 查看原任务；是否取消按能力配置 |
| 已确认成功 | 对应结果；涉及权益时还要有交付事实 | 查看、下载、复制或继续下一步 |
| 已确认失败 | 可读原因；结算状态另行说明 | 满足重试条件后主动重试 |
| 超时、断网、无法确认 | “结果待确认，请稍后查看记录”等明确反馈 | 查询原任务或记录；不自动重试付费、兑换、发布动作 |

前端等待结束不等于服务端任务结束；失败不等于已退款；扣分不等于权益交付；生成成功不等于作品发布。相关页面保留同一任务、订单或内容身份进行恢复。技术幂等方式由研发设计，但产品验收必须覆盖重复点击、重连及回到页面后不产生重复业务结果。

## G06 限时积分与自动奖励

| 对象 | 统一规则 |
|---|---|
| 积分账户 | 只使用限时积分；发放必须有有效期和到期时间，不新增普通、永久积分 |
| 可用余额 | 使用已确认账务值；待到账、未知金额不能算入可用余额；未知显示“—”，不能伪装成 0 |
| 消费 | 按最早到期批次优先扣减；提交时重新判断余额、价格和业务资格 |
| 返还 | 关联原消费流水并沿用原批次到期时间，不延长有效期；未过期部分恢复可用，已过期部分不恢复可用并说明原积分已过期；多批次分别判断 |
| 活动、邀请、签到 | 按配置满足条件后自动发放，不提供领取积分按钮；完成、有效资格、发放及到账分别确认 |
| 到期提示 | 明确即将到期数量与到期信息，能进入明细；过期积分不再参与可用余额计算 |
| 记录 | 发生时间、业务来源、变动金额、余额/结算事实可追溯；待处理与已到账不能混为一条成功记录 |

业务时间见 G-TIME。原批次过期后返还不恢复可用，显示原积分已过期；返还金额与恢复可用金额的字段待研发映射。

### 返还结算与补偿

兑换失败后的积分返还关联原扣减流水，沿用原积分批次的到期时间，不重新计算有效期。返还结算确认时，原批次未过期的部分恢复可用；已过期的部分不恢复可用，说明“原积分已过期”。若一次扣减来自多个批次，逐批次判断，不将整笔积分一律恢复或一律作废。

原返还仍在处理或结果未知时，展示“积分返还处理中”并查询原记录，不提前显示已返还或增加余额。结算确认后，记录明确区分返还金额与其中恢复可用的金额；已过期部分附原批次到期信息，避免将“已返还”理解为全部可用。具体字段和账务枚举由研发核对，以真实账务结果展示。

因系统故障需要特殊补偿时，由运营核对原记录并按既有授权流程处理，本期不新增自动补偿规则，不承诺联系客服必然获得补偿。补偿与原返还分别留痕，不通过修改原批次期限实现续期。

验收：返还确认时未到期部分恢复可用，恰好到期及之后不恢复；混合批次分别计算；返还处理中不提前增加余额；特殊补偿不冒充原返还或自动触发。

## G07 B 端维护与 C 端生效

| B 端动作或状态 | C 端影响 |
|---|---|
| 编辑、保存草稿 | 不覆盖当前公开版本；编辑者可见的草稿不等于普通用户可见 |
| 审核通过 | 不自动推导已经发布；按该对象发布规则生效 |
| 发布或配置生效 | C 读取有效公开版本；展示位、专题、详情及搜索使用同一对象身份 |
| 下架、删除、无权限 | 不再进入公开分发；旧链接给出不可访问反馈，保留合理返回；关联内容分别处理，不连带删掉原帖讨论或历史交易 |
| 关闭应用执行、商品停用 | 禁止新的执行或兑换；已存在任务、兑换与积分记录继续可查询 |
| 配置变更 | 展示使用新有效版本；提交前重新校验；正在处理的任务和已成立交易不静默套用新的价格、奖励或条件，具体生效边界在对应模块确认 |

B 端内部审核、风控、核验日志不直接作为 C 端状态文案。用户仅需知道当前结果、原因以及下一步。配置缺失不生成看似有效的零价格、默认奖励、默认链接或可执行入口。

## G08 弹层、短提示与常驻反馈

| 反馈内容 | 承载方式 |
|---|---|
| 已加入、复制成功等单次完成反馈 | 按页面需要使用短提示，完成后自动消失，不占据正文长期位置；喜欢、收藏成功只更新选中状态和数量，关注反馈按页面定义，不额外统一增加成功提示 |
| 输入错误、权限限制、可恢复失败 | 字段旁或对应操作区域内展示，直到修正或退出；需要用户行动的信息不能一闪而过 |
| 删除、兑换等需要明确确认 | 产品统一确认弹层；取消不执行；提交中防重复；不用浏览器系统弹窗替代 |
| 未知结果或持续处理中 | 当前业务区域保留查询路径，不能只有瞬时提示 |
| 弹层打开、关闭 | 标題与关闭钮同一层级；焦点进入弹层、关闭后回触发入口；背景不误操作；长内容在弹层内可滚动 |

PC 与移动端可使用不同尺寸与位置，但相同业务的内容、资格和结果保持一致。公共反馈集中展示组件范例，业务页面只增加会改变内容或操作的代表状态。

## G-TIME 业务时间

业务时间统一采用北京时间（Asia/Shanghai，UTC+8），以服务端业务时间判断，不受设备时区或设备时钟影响。活动开始时刻包含、结束时刻不包含，即开始≤当前时间＜结束；到结束时刻即结束，积分到期时刻起不可用。签到自然日及邀请日限额按北京时间00:00切换，月限额按每月1日00:00切换。界面标注与实际判定一致；仅给日期的截止日若表示整日有效，统一换算为次日00:00排他结束，避免当天少算。

验收：设备切换时区不改变签到归属日；活动结束前一瞬仍在期内，恰好结束时刻不可继续；北京时间月底跨入次月后按新月份统计。

## G-COUNT 字符计数

昵称、简介、评论、发布与搜索按用户可感知字符（Unicode扩展字素簇）计数：汉字、英文字母、数字各1个，组合表情整体1个，内部空格及换行各1个，CRLF作为一次换行。按对应字段既定首尾空白处理规则处理后计数；不更改页面已定上限。界面计数与提交校验使用相同口径，超限提示并保留输入，不静默截断。

验收：“你好AB12”计6个字符，“A B”计3个，家庭组合表情计1个；内部换行计1个。每字段上限N可提交、N+1提示且保留输入。

## G09 内容下架、恢复与删除

### 主动下架与恢复

作者可主动下架本人作品、帖子，操作菜单提供入口并二次确认。下架后从公开列表、搜索、作者主页移除，其他人访问原链接显示不可访问；本人在我的内容仍可查看、编辑、删除。

作者主动下架后，未修改内容且原审核仍有效时可重新发布；修改过的内容须重新审核。保留原内容身份与首次发布时间，不刷新排序或投稿资格。后台治理下架与作者主动下架分别记录；后台管理员可直接恢复上架，封禁内容通过解除封禁操作恢复，二次确认并按实际成功结果刷新。后台恢复不等同于开放作者自行解除治理限制。下架对投稿资格和奖励的影响遵循活动页面规则。

### 已发布内容删除

作者可删除自己的作品和帖子，须二次确认，本期无回收站。取消不改变内容，失败保留原记录，结果未知先核对原请求。删除成功后从公开列表、搜索和作者主页移除，原详情不可访问，所属评论及互动不再公开展示；不连带删除其他帖子或生成资产。

其他帖子、教程等引用方直接隐藏已删除对象的引用卡片、缩略图与入口，不显示“内容已删除”占位；引用方自身合法正文和讨论保留，不因引用失效整篇下架。此规则仅针对作品、帖子被删除后的引用展示，父评论删除同样不展示删除占位，合法回复继续展示，禁止继续回复被删除项。

保留必要投稿、参与和奖励记录，注明原内容已删除，记录不再开放原正文入口。要求作品公开的任务在发奖前重校验，删除后不满足该项资格；已到账奖励不因普通删除自动扣回，违规作弊仍按治理规则处理并保留流水。

验收：删除需本人权限和确认；删除后原详情不可访问；引用方无被删对象卡片也无占位且自身正文仍在；生成资产、必要参与及奖励记录保留。

## G10 草稿保存、恢复与删除

|场景|规则|
|---|---|
|跨设备恢复|同账号PC与手机均可恢复成功保存的草稿，包含文字、选项和上传成功且保存关联的素材；未保存输入、上传未完成文件不承诺跨设备恢复|
|期限与续期|手动草稿自最近一次成功保存起保留30天；打开不续期，保存成功才重新计算。到期不可继续编辑；不套用于待审、已提交、退回稿或生成记录|
|素材失效|保留文字、选项和其他有效素材，标出失效项并允许移除或重新上传；必需素材未补齐不可发布，不清空整份草稿|
|删除|二次确认后删除，本期不设回收站；取消不变，失败保留原记录，结果未知先查询原操作，不伪造删除成功|
|关联边界|删除草稿不连带删除来源作品、生成记录或其他内容正在使用的素材；物理文件清理由研发按有效引用处理|

验收：同账号跨端恢复成功保存内容；仅打开不改变保存时间；模拟单张素材失效，其余字段仍可编辑；取消删除保留草稿，确认成功后移除草稿且来源对象仍在。跨设备存储、素材有效性与物理清理的服务字段和实现待研发核对。

1. 各分类仅改变作品区，详情返回恢复分类及位置。
2. 移除一个入选作品后其他卡片顺序稳定，重新公开不自动入选。
3. 无有效 Banner 不留空白占位；作品失败不遮掉有效专题。
4. PC 聚焦与手机常显信息可读，图片视频不拉伸。

#### PC 弹层与提示

|对象|触发与内容|关闭与后续|

### 帖子详情

#### 页面职责与端差异

阅读和讨论一条公开帖子，来源包括交流、圈子、搜索、作者及本人内容。PC 左侧正文、图片、引用和展开评论；右侧在导航下常驻作者、互动、所属圈子及发帖入口。手机顶部为返回、作者和关注，评论使用全部评论弹层。

引用失效在原详情内承接，不另设“部分完成”页面。

#### 信息与条件

|字段|规则|
|---|---|
|正文与媒体|完整标题、正文、时间和媒体；图片可放大，不用摘要替代完整内容|
|所属圈子|有实际归属才显示名称、头像、简介、人数及加入关系；无圈子隐藏该区|
|真实引用|仅维护的原对象，点击进入对应详情；引用不是帖子正文副本|
|作者与互动|作者进入公开主页；喜欢、收藏、评论、分享沿用四项层级|
|PC 右栏|不重复评论列表和推荐圈子；楼中楼回复动作紧跟正文，名称与回复对象分层|

#### 动作与流转

|动作|前置|结果|
|---|---|---|
|评论／回复|帖子可读且互动开放|PC 定位左侧评论，手机打开弹层；回复指定评论，可取消回复|
|删除评论／回复|仅本人条目|不提供编辑；删除先确认，删除条目不展示占位，合法回复继续展示|
|查看引用|原对象仍可访问|进入原详情，回来恢复正文位置|
|圈内发帖|已加入且圈子可接收帖子|进入帖子编辑并预选当前圈子|
|无圈子发帖|登录|进入普通帖子编辑，不继承上次圈子|
|分享|帖子有有效定位|复制原帖链接，PC 卡片分享也落同一详情|

#### 状态与输入边界

|触发|下一状态与 C 端反馈|
|---|---|
|仅引用失效|保留合法正文与讨论；被引用对象删除时隐藏整个引用区，不保留旧缩略图或占位；其他失效原因按对应可访问规则处理|
|帖子下架或无访问资格|不可访问，不从缓存显示受限正文，停止互动|
|评论关闭|停止新提交，保留可恢复输入与正文位置|
|评论为空白或超出 1,000 字|就地校验，不提交；回复对象与文本均保留|
|提交失败或结果未知|遵循 G04／G05，不清空输入或把未确认结果当新评论|
|关闭手机评论弹层|回正文原位置，保留未提交文字|

登录恢复后仍由本人提交。喜欢、收藏、关注按最终关系更新，不把快速连点当多次增加。评论权限和删除呈现遵循 G04，每条最多1张，JPG/JPEG/PNG/WebP，不超过10MB。

#### B 端维护与 C 端影响

帖子正文、公开状态、圈子归属和引用分别维护；失效引用不自动下架合法帖子。普通圈子关闭停止加入及新发帖，历史帖按自身公开状态阅读；违规整体限制另按治理结果。帖子不因篇幅长或有教程内容自动成为教程。

#### 验收

1. PC 圈子卡片分享与手机交流点击进入同一帖子和讨论。
2. 无圈子帖不留圈子占位；圈内发帖保留指定圈子。
3. 被引用对象删除时隐藏引用区，引用方合法正文与讨论仍在；帖子自身下架则隐藏正文及旧媒体。
4. 评论校验、回复、删除和手机关闭恢复满足 G04，PC 评论入口准确定位。

#### 帖子媒体预览

点击帖子图片打开同一图片组的大图预览，默认定位所点图片；多图支持缩略图和左右切换。点击图片不同时触发卡片导航或评论展开。关闭／Esc 返回原帖子与滚动位置，PC 不为此改成另一套帖子详情。

#### 共用媒体预览

点击参考图片、参考视频或正文图片，使用共用媒体预览组件；从所点素材开始，同组多项提供前后切换、缩略图与序号，图片等比完整展示，视频提供播放控件且不自动播放。关闭或 Esc 返回原页面与输入位置，视频关闭停止播放；加载失败保留关闭和切换入口。纯媒体预览不承载生成参数、发布或计费操作，生成结果页保持独立。

#### 主动下架与恢复

本人下架、重新发布与后台恢复遵循 G09；下架后本人仍可在我的内容查看、编辑、删除。未修改且原审核有效可重新发布，修改后重新审核；原身份和首次发布时间不变，作者不能自行解除后台治理限制。

#### 下架、投稿资格与奖励

作品下架后保留原投稿记录，注明原作品已下架，不删除参与记录。要求作品公开的任务，在发奖前再次校验公开状态；下架期间不满足该项发奖条件，签到等无关任务不受影响。

恢复公开后沿用原投稿记录，重新校验活动期限及资格，不重复投稿或重复发奖；活动已结束时不自动补发。普通下架不自动扣回已到账奖励；违规或作弊由后台按活动规则处理，保留处理原因与积分流水，不由前端自动追扣。


#### 已发布内容删除

本人删除作品、帖子遵循 G09：二次确认，本期无回收站；失败保留，未知先查原请求。成功后原详情与所属互动不再公开，引用方隐藏被删对象且无占位，保留自身合法正文；生成资产、必要参与与奖励记录保留。公开资格与违规奖励处理按活动规则执行。

### 作者主页

#### 页面职责与端差异

查看某位作者公开资料、作品和帖子，决定是否关注。入口包括作品、帖子、搜索及个人关系。PC 页头左侧资料与关注，右侧获赞／关注／粉丝统计；手机按已有作者资料和内容流组织。保留来源返回，不重复作者主页标题。

#### 字段与条件

|字段／栏目|规则|
|---|---|
|公开资料|头像、昵称、公开简介、实际官方或认证身份；身份标签不得从昵称推断|
|统计|获赞、关注、粉丝、公开内容数量只读，取真实统计；不默认开放关系名单|
|内容栏目|固定作品、帖子两栏及各自公开数量；总数只包含这两类|
|作品卡|多比例流；PC 图片底部常显标题与互动数，不反复显示同一作者|
|帖子卡|PC 左侧阅读列表含标题、摘要、可选配图、日期、所属圈子及互动数量；右侧展示从作者公开帖子关联得到的圈子，不读取私人加入名单；点击进入原帖子或对应圈子。手机保留原列表|
|排序|各栏首次公开时间倒序，同时间按标识排序；编辑旧内容不刷新发布时间|

普通或官方账号均不增加 AI 应用、教程栏目；应用与教程由官方维护，使用应用生成的公开作品仍归作品作者。

#### 动作与状态

|动作／触发|前置|结果与反馈|
|---|---|---|
|关注／取消关注|按需登录，对象可操作|按最终关系更新按钮与粉丝数，不另弹成功层；失败恢复|
|切作品／帖子|栏目存在|各自展示公开内容；空栏保留，不隐藏栏目|
|点内容|该内容仍公开|进入原详情，返回恢复原栏位置|
|分享|作者有有效定位|复制作者链接，接收方仍按权限阅读|
|主页受限|账号或主页状态生效|中性状态反馈，不保留可操作的关注按钮|
|单件内容下架|该件不可访问|移除该件，不自动清空作者所有合法内容|

#### 输入与私密边界

本页无资料编辑、发帖或生成输入。本人访问也不能把私人管理数据并入公开主页：不显示积分、签到、邀请收益、草稿、生成记录、收藏、私人圈子关系、活动参与明细或管理操作。关系数量可展示不代表可打开名单。账号停用或注销不推导新的删帖政策；既有内容逐项按最新公开与治理状态判断。

#### B 端维护与 C 端影响

个人公开资料、官方／认证属性与内容公开分别生效。运营维护应用或教程不会增加作者公开内容数；作品被专题收录、首页推荐也不复制一条作者内容。公开版变更同步卡片，待审材料不进入作者栏。

#### 验收

1. 普通和官方账号均只有作品、帖子，数量不含应用教程。
2. 已关注、未关注、取消失败表现一致，粉丝数不因重复点击累加。
3. 空帖子栏保留，编辑旧帖不顶到最前。
4. 作者受限与单件内容下架分开，私人资料不出现在主页或分享入口。

#### 帖子媒体预览

点击帖子图片打开同一图片组的大图预览，默认定位所点图片；多图支持缩略图和左右切换。点击图片不同时触发卡片导航或评论展开。关闭／Esc 返回原帖子与滚动位置，PC 不为此改成另一套帖子详情。

入口可用→选择→登录或目标表单；关闭→来源。原对象、圈子或活动失效时保留可恢复输入，停止原操作，不能悄悄改成普通发布。私有生成、保存草稿、提交、公开及获奖分别判断。

#### B 端影响与验收

B 模型启停影响生成目标，活动配置影响生产入口、投稿类型和资格；只有已有目标真实有效时提供入口，不用通用首页代替失效目标。账号生产限制仅阻断对应动作，浏览和历史记录按权限承接。

1. 移动三入口各到正确表单，PC 不出现选择层。
2. 普通入口不带旧活动，圈内入口带正确圈子。
3. 活动生成再发布识别同一任务；取消与登录往返不产生作品或扣分。
D-A02：跨设备输入恢复与正式能力开放范围待研发映射。

### AIGC 生成

#### 页面目的与布局

社区工作台生成图片、剧本或视频，并由本人选择结果发布；应用去 MakeNow 执行是另一条路径。PC 全屏可收起：顶部标识及收起、中部当前类型记录、底部固定输入。收起保留输入与记录，重新打开继续；移动端沿用工作台、历史和预览布局。

#### 字段与限制

| 字段 | 约束 |
|---|---|
| 类型、模型 | 图片／剧本／视频；仅可用且已具备当前输出能力的模型可选 |
| 提示词、参考素材 | 提示词必填；参考图可预览移除，图片与视频上限按当前模型显示，现有界面分别为 4 张／1 张，不作为所有模型固定上限 |
| 比例、画质、时长 | 只展示所选模型支持的参数；剧本不显示图片及比例，切换模型重新校验保留输入 |
| 投稿活动 | 默认不参与；可选有效且允许当前类型的活动，切换清除旧任务关联 |
| 预估积分 | 由当前模型与参数报价提供；未知不能按零价生成 |
| 记录 | 任务身份、时间、提示词、模型参数、参考素材、结果及状态；历史缺失字段显示未知 |

#### 动作与状态流转

| 当前／触发条件 | → 结果／可用操作 |
|---|---|
| 输入、报价、可用限时积分及活动资格有效；本人生成 | 同一任务记录排队→生成中→成功或明确失败 |
| 进度未知或请求超时 | 查原任务，不认定失败、不直接重复生成 |
| 明确失败 | 恢复输入，由本人调整后重试 |
| 部分结果 | 仅展示已确认结果与结算，不推定全额退费 |
| 成功；打开预览 | 左侧媒体／剧本，右侧参数、可复制提示词、参考素材；可下载、继续调整、发布 |
| 继续调整 | 恢复原任务输入 |
| 本人发布 | 进入作品编辑，带结果、提示词及活动身份；生成成功不自动公开 |
| 原活动失效 | 保留关联识别、停止新投稿；本人取消关联后才可普通发布 |

参数菜单向上锚定，选中收起；活动较多仅菜单内滚动。引用同款只恢复可复用素材和已确认模型参数，不能因看到参考图而获得使用授权。

#### 异常与 B 端影响

素材失败保留文字和有效素材；模型停用、参数失效、报价变更指出具体项，保留输入重新选择／确认，沿用 G03、G05。供应商原始报错不向用户直接展示。任务占用、最终扣费、释放读取账务结果；最早到期扣减和原批次返还遵循 G06，释放不延长积分有效期。

B 模型维护能力与报价，生成记录负责任务结果，积分记录负责费用；活动负责人维护资格及任务规则。配置变化影响下一次请求，不改写已有结果。MakeNow 的任务和成果不自动导入社区，跨站成果传递只按已核实合同提供。

#### 验收与待明确

1. 模型切换控件与校验一致，收起重开保留输入。
2. 超时可找回原任务，生成不自动发布，历史发布保留活动。
3. 报价未知、积分不足不误发起；释放费用不延长有效期。

D-A01：正式模型能力、报价与部分成功／取消／释放费用映射；生成资产保留见下文；跨设备生成输入与参考素材恢复能力交研发核对，不套用草稿承诺。

#### PC 结果与继续创作

生成完成后打开完整结果视图；PC 单列展示图片、剧本或视频。同一任务的下载、参数、提示词、参考素材、继续调整和发布作品共用结果视图规则。结果中提供前往 MakeNow 继续创作入口，打开已配置的安全站点，使用当前账号继续；素材、参数与费用由用户在 MakeNow 中确认。账号已互通；本期不提供素材自动带入、任务同步和结果回传。

#### 视频参数与参考素材

PC 视频生成提供模型、比例、画质、时长、活动选择；选中后菜单收起并保留提示词。可选值、组合及计费以模型能力配置为准，720p／1080p、5秒／10秒不是固定支持范围。参考视频支持预览、移除；格式、体积与上传校验待模型接口映射。

提交前先确认登录与可用积分；积分不足时 PC 生成按钮置灰并显示“积分不足”，不可点击，不弹出积分不足对话框；保留全部输入、不创建任务。继续调整遇到失效参考素材时明确提示重新选择，不以其他图片替代。任务完成与扣费、返还、到账的一致性待研发验证。

#### PC 参考素材与生成进度

参考图片和可选参考视频入口放在同一素材行；未选择视频时使用轻量文字入口，不另占一张说明卡片。格式与大小限制在入口提示及选择校验中提供；选择后可预览、移除。

生成中卡片的百分比与进度条一致，仅在服务端返回可靠进度时显示百分比；无进度值时显示“正在生成”及不定进度，不按时间编造百分比。100% 不单独代表结果可用，仍以任务完成且结果可访问为准。

#### 共用媒体预览

点击参考图片、参考视频或正文图片，使用共用媒体预览组件；从所点素材开始，同组多项提供前后切换、缩略图与序号，图片等比完整展示，视频提供播放控件且不自动播放。关闭或 Esc 返回原页面与输入位置，视频关闭停止播放；加载失败保留关闭和切换入口。纯媒体预览不承载生成参数、发布或计费操作，生成结果页保持独立。

#### 生成资产保留

AIGC生成结果属于用户资产。本期不设置保存到期时间，不增加到期提醒、到期失效或按期限自动清理；手动草稿30天规则不适用于生成结果与生成记录。生成记录本期不支持用户删除，进行中与已结束任务均不提供删除或批量删除入口，不设置删除确认及回收站。保存到草稿、发布作品与生成来源保留关联，草稿到期或删除不连带删除生成资产；既有内容权限和违规治理规则仍分别执行。本期不处理保存期限，不将其宣传为永久存储服务承诺。

### 发布作品

#### 页面目的与字段

作品表单按成果、创作信息、发布设置组织；图片、视频、文本共用业务规则，页内不切换为帖子。PC 与手机保留保存草稿、发布作品，返回用顶部入口，不另设整页预览或取消确认。

| 字段 | 限制与恢复 |
|---|---|
| 类型、标题、正文 | 标题去首尾空白必填，最多 60 字；正文最多 20,000 字；文本正文必填且无上传区 |
| 图片／视频 | 图片最多 4 张、单张 20 MB；视频最多 1 段、300 MB、10 分钟；不能混用，类型与素材一致 |
| 素材顺序、封面 | 可预览移除，图片可拖动；首图封面，添加卡片最后，满额隐藏、移除恢复 |
| 提示词、模型 | 提示词去首尾空白必填，模型普通发布选填；生成结果带入并可修改 |
| 分类、话题、引用 | 分类单选、话题多选，取有效配置；引用通过选择真实站内对象形成可移除卡片 |
| 活动及任务 | 默认不参与；只选有效、具资格、允许当前作品类型的活动；保留来源身份 |

#### 动作与状态转移

空白／私人草稿／退回修改→编辑。保存草稿允许字段不完整；成功保存才更新时间，未提交手动草稿自最近保存保留 30 天，不套用于生成记录或已提交材料。已有媒体切换类型先由本人移除，文字不静默丢失；预览关闭回表单并保持顺序。话题连续勾选不关闭，完成、外点或 Esc 收起回显。

发布前校验必填、上传完成、尺寸时长、素材数量、有效引用和配置；活动另校验参与关系、内容类型、指定分类话题及要求的模型、场景和案例，按其有效规则执行，不能把某活动限制变成所有作品限制。切换活动清除旧任务关联；失效活动保留草稿，不自动普通发布。

提交中锁定重复动作；成功进入我的内容，按服务端显示审核中／已公开，不把受理当公开。待审稿先撤回本次提交再修改，撤回不自动下架已有合规公开版；新稿重新审核，旧结论不沿用。

#### 异常与 B 端影响

字段错误定位具体项，上传或提交失败保留文字、设置和可恢复素材；不能恢复的本地素材明确要求重选。未知结果查询原请求；版本冲突允许查看当前版本、复制未保存文字及刷新继续，不覆盖新版本，沿用 G03。

B 内容审核决定公开版本和用户可读原因；活动配置决定投稿资格，资格与奖励另行结算；B 下架不删除本人可处理记录，也不允许旧缓存展示受限正文。保存分类、话题、引用、活动及来源用于草稿、登录恢复和修改。

#### 验收与待明确

1. 缺标题／提示词、文本空正文、超限媒体及混用均阻断。
2. 满额隐藏添加，移除恢复；排序与预览返回顺序一致。
3. 待审撤回后修改，未知提交不生副本，活动结束不降级普通发布。

草稿跨设备恢复与删除遵循 G10；正式分类话题配置交研发核对；活动规则调整由运营人工控制，不新增规则版本兼容。

#### 共用媒体预览

点击参考图片、参考视频或正文图片，使用共用媒体预览组件；从所点素材开始，同组多项提供前后切换、缩略图与序号，图片等比完整展示，视频提供播放控件且不自动播放。关闭或 Esc 返回原页面与输入位置，视频关闭停止播放；加载失败保留关闭和切换入口。纯媒体预览不承载生成参数、发布或计费操作，生成结果页保持独立。

#### 已发布作品追加投稿

允许在我的内容中对本人当前已公开的作品追加投稿；一件作品可参加多个活动，各活动分别校验资格。同一作品在同一活动同一期只能投稿一次。活动开始前发布的作品不能参加，不提供接受活动前作品的运营开关；发布时点按作品首次公开时间判断，编辑不刷新该时间。其他活动有效期与资格规则仍适用。

草稿、审核中、未通过、已下架的作品不可选择。我的内容保留一件原作品；我的投稿按作品与活动期次分别展示记录，提供对应活动和稿件入口，不新增重复投稿进度。投稿成功不代表获奖，满足奖励条件后自动发放。

#### 草稿保存、恢复与删除

遵循 G10：同账号跨端恢复成功保存的文字、选项及已上传关联素材；未保存输入和未完成上传不保证跨端恢复。最近成功保存起保留30天，打开不续期；待审、已提交、退回稿与生成记录不套用期限。素材失效保留其他内容，必需素材补齐才可发布；删除二次确认且不连带删除来源内容、生成资产或仍被使用的素材。

验收：跨端恢复成功保存内容；仅打开不续期；单张素材失效不清空其他字段；取消删除不变，删除成功后来源对象仍在。

在商城原页核对积分兑换，并查看同一次请求的结果。PC 为居中弹层，手机沿用商城确认层；关闭回商城且保留商品位置。不新建兑换中或成功落地页。确认兑换、兑换成功、积分不足、兑换失败统一在本页展示，不在弹层目录重复列出。

#### 字段与限制

| 字段 | 展示与约束 |

| 结果、卡密、产品入口 | 仅本次成功取得的有效卡密可复制；站点使用已配置的安全入口 |

#### 动作前置与状态流转

#### 积分与 B 端影响

消费按最早到期批次优先扣减；返还关联原扣减流水并沿用原批次到期时间，不延长有效期。原批次已到期时，展示实际返还及可用结果，不承诺恢复可用积分。B 商城维护商品、站点、库存和生效范围；确认层重取有效版本。兑换记录负责订单和权益结果，积分记录负责扣减或返还事实；停用商品不删除旧兑换。运营异常处理产生用户可读结果，C 端回到对应请求。

#### 验收与待明确

1. 游客返回仍需主动确认，报价变动、积分不足、缺货不误扣。
2. 超时先查原记录，有扣分无卡密不误报成功。
3. 复制对应本次卡密，退款不生成新有效期。

D-A06：权益待交付与返还的服务端状态、金额及到期字段待研发映射。

#### 兑换异常反馈

|场景|用户可见反馈与操作|
|---|---|
|已扣积分但卡密暂未返回，结果尚未确定|显示“兑换结果确认中”，提供查询原兑换记录入口；不显示成功，不引导重复兑换|
|明确失败|显示用户可理解的失败原因；未扣分如实说明，已扣分区分“积分返还处理中”与“已返还”，不提前增加余额或声称到账|
|长时间未取得结果|提供现有联系客服入口，由运营核对原兑换记录；不自动新建兑换，不虚构处理时限|
|商品后来下架|成功兑换记录和原卡密仍可查看、复制，商品下架不删除历史记录；卡密自身有效期按原权益规则执行|

“已返还”只证明返还结算已确认，不等于原已过期积分重新变为可用；余额和有效期沿现有积分规则。查询、联系支持及人工处理均关联原兑换记录。原请求明确终止、未扣分或返还已确认后，如仍需兑换，由本人重新核对有效商品、余额及资格后主动发起。

验收：已扣未交付不报成功；返还处理中不显示已到账；长时间未知可联系支持且不重复下单；商品下架后原成功记录可查可复制。

#### 返还与原积分有效期

返还结算遵循 G06：按原扣减批次逐项判断，未到期部分恢复可用，已到期部分不恢复并说明“原积分已过期”；有效期不续期。处理中不提前增加余额；结算记录区分返还金额与恢复可用金额，已过期部分附原批次到期信息。状态、金额和到期字段待研发映射。

验收：混合批次分别计算；恰好到期不恢复可用；待返还不提前加余额；补偿不冒充原返还。
