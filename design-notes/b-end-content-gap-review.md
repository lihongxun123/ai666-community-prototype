## 能力对照

| 能力 | 本地已有基础 | 改版处理建议 |
| --- | --- | --- |
| 作品管理 | 列表、筛选、详情、审核、上下架、封禁、爆款操作及作品编辑 | 复用列表与治理基础；按已确认职责限制正文修改权限，补关联信息；爆款标识不等于专题收录 |
| 帖子管理 | 当前入口称“闪念管理”，使用帖子对象，支持详情、审核、精选和上下架 | 以帖子管理承接已确认的社区表达；补圈子归属与关联作品，不复制为新的内容对象；旧入口兼容另行核实 |
| 审核工作台 | 汇合作品和闪念的待审核内容，提供通过、拒绝及原因 | 复用待审核工作入口；不将审核通过等同推荐或应用可用，真实审核后状态需接口核实 |
| 教程基础编辑 | 标题、板块、图文／视频形式、时长或难度、摘要、封面、排序、Markdown 正文 | 保留灵活正文；按已确认规则补使用条件、来源与署名、授权依据、维护信息以及结构化关联 |
| 教程草稿与发布 | 创建草稿、更新、发布、下架、删除及详情回读 | 复用基本路径，但新建草稿当前仍校验标题、板块、形式和正文；应区分草稿保存门槛与发布完整性要求 |
| 教程预览 | 编辑器正文预览与独立教程详情预览入口 | 不等同于改版 C 端手机／PC 的实际效果预览；最终展示与关联入口需要配套验证 |
| 编辑与发布权限 | 教程存在查看、新建、编辑权限；前端权限目录将教程更新、发布、下架、删除归于编辑权限；审核工作台有通过／拒绝权限 | 需落实已确认的编辑、发布分离，并核实服务端授权 |

## 三项容易误判的边界

1. **形式选项不证明完整视频能力。** 教程可选择视频形式，但 Markdown 工具栏未见专用视频上传操作；视频嵌入、保存与 C 端播放需单独验证，不能据此宣称已支持完整视频教程链路。
2. **保存草稿不证明已发布版本隔离。** 当前已发布教程“保存修改”调用同一更新接口，本次未见独立待发布版本标识或切换流程。不能承诺保存后线上保持原样。此前明确确认的专题、应用与资源更新隔离不能据此视为已实现；教程是否采用同样的更新隔离仍需确认。
3. **已有作者展示不等于来源授权管理。** 本次教程编辑字段与提交数据未见合作供稿、授权改编、编辑署名、授权依据、维护负责人或应用／资源关系字段。不能以正文放一个姓名、链接替代这些管理关系；后端是否已有字段需另核。

## 页面结构建议（待确认）

内容管理下保留作品管理、帖子管理、官方教程管理与审核工作台。深度案例使用适合的帖子或教程承接，不新增独立“深度案例管理”。

教程编辑按四组信息组织，同一编辑页完成：

1. 基础信息与正文。
2. 使用条件与关联内容、应用、资源。
3. 来源、作者／编辑署名与授权依据。
4. 维护信息及保存、预览、发布操作。

分组不代表所有字段必填；字段是否必填及校验时机需进一步明确，已确认的授权和资源可用性约束保留。普通帖子继续轻发布，后台以治理为主；不因内容深入强制转换成官方教程。

作品、帖子、教程、专题、圈子、应用与资源的 C/B 现状对照已归入[内容维护总表](content-maintenance-matrix.md#现有能力与改版目标对照)。全站菜单调整、接口字段及研发排期尚未定版。
