## 修正项

| 范围 | 修正 |
|---|---|
| 作品需求 | 删除普通用户作品不可编辑的旧约束，与后台可编辑全部作品保持一致 |
| AI应用方案与流程 | 删除混入的用户帖子待审、旧公开版本分支；明确仅官方维护、免审保存 |
| 商城流程 | 改为编辑产品的启用状态及有效期，不描述不存在的独立上下架按钮 |
| 公告管理 | 列表与详情共用操作；已发布公告可下架并编辑，仅下架成功后打开编辑；详情补阅读数 |
| 公告文档 | 统一全部注册用户、必填摘要、草稿保存、下架编辑及再次上架流程 |
| 需求与流程覆盖 | 校验器改用当前页面集合，移除废弃页面需求，修复标题间距和整页重复文案，补回内容生态、活动与激励流程 |
| 教程详情 | 修正字段跨度，消除详情表格布局警告 |
| 圈子编辑 | 表单预挂载后初始化；失败演示标记改为状态变量，消除表单与静态检查警告 |
