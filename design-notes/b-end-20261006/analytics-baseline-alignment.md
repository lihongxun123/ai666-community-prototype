## 新社区业务统计：已确认补充

范围与计数边界已确认，见 `docs/versions/v1.0/business-logic/cross-page/AI666_社区统计补充需求_V0.1.md`。现已加入内容生态、活动与激励、指标中心的社区页签，不覆盖原有V0.2。

| 业务变化 | 需要明确的统计范围 |
| --- | --- |
| 圈子与帖子 | 区分浏览圈子、浏览帖子和圈内发帖；点赞、转发、收藏归属于帖子；按对象类型分组 |
| AI应用 | 浏览、有效使用入口点击、点赞、转发、收藏；使用入口点击不能表示 MakeNow 创作成功 |
| 专题 | 专题详情浏览与专题内内容点击分开；不将一次专题浏览累计为多次内容浏览 |
| 活动新增任务 | 新任务类型进入原有参与、完成、奖励口径；不新增指定某个圈子、应用、专题的范围配置；奖励按自动发放结果统计 |
| 模型广场 | 仅统计外部入口跳转；外站浏览、调用、消费不在社区可证明的事件范围内 |

## 研发交接

沿用 V0.2 的时间边界、去重、归因、观察窗与快照规则。H-05/H-08 的实际流水类型映射仍需研发确认。数据缺失、观察窗未满、分母为零与真实零值不得合并。

原型为演示数据，不连接真实接口，不实现计费或统计管道。本次验证覆盖页面、筛选、下钻、返回和定义查看，不代表105个展示值的生产数据验收。
