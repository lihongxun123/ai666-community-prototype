# 运营配置复核修复

- 发布单个对象时，其他对象使用各自已保存的公开快照；未发布草稿不进入共享公开源。当前对象先计算最终状态，再保存公开快照，避免串行发布污染其他草稿。
- B 端作品、帖子、教程、应用统一读取运营分类源。停用分类停止新选择，既有分类保留只读历史选项；同类型合并同步迁移作品及内容草稿/公开版本，保留对象身份与正文，不自动下架。分类稳定标识用于选项识别，既有名称存储兼容。
- 编辑页显式非法 ID 返回不存在，不再替换成首条数据；无 ID 的演示入口仍选取样本。
- 编辑状态去重；活动说明与预览复用 ContentBlockPreview，支持编辑器的 u/sup/sub。
- 活动源写入移至提交成功或查询原操作确认之后，失败和结果未知不提前发布活动。

验证：TypeScript 无错误；operations-management/model、taxonomy-adapter、work-management 的 targeted oxlint 通过。确定性样本验证其他草稿隔离、当前最终发布状态、20 项分类的类型隔离、停用与历史选项保留。浏览器与最终 build 由主任务汇总验证。本次未修改共享导航、contracts 或平台组件。

边界：以上分类消费与合并覆盖新的 B 端 content/work 数据源；不将本地原型数据迁移等同于真实后端或线上数据迁移。
