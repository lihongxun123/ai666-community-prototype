# 多元拾光重大改版：跨产品使用、MakeNow 工程分享与应用供给需求


状态：目标需求已确认，MakeNow 真实能力与定向链接待核验。

## 1. 产品边界

本期面向文字、图片、视频。AI 应用由社区承接露出、介绍与讨论，由 MakeNow 承接输入、生成、费用、任务和结果；社区不建设应用执行页。MakeNow 同时承接画布、节点与工程制作。未来电商 Agent 尚未上线，不作为当前执行入口。复杂编辑在 PC，手机可阅读并获得定向链接。ComfyUI 工作流先按真实取用条件作为资源，不建设任意工程自动部署平台。此处只调整 AI 应用模块，不推导既有社区 AI 创作或轻创作能力全部迁出。

对象关系、移动端和后台职责分别见[全站内容模型](site-content-model.md)、[移动端架构](mobile-architecture.md)和[B 端架构](b-end-architecture.md)。MakeNow 的复制、生成、扣费、发布、账号互通、权限隔离、回流和手机兼容仍待实际核验；本文件不将目标流程视为已接通能力。

## 2. AI 应用：从理解到结果的共同产品规则

### 2.1 入口选择与职责

同一应用只维护一个社区介绍身份。详情说明任务用途、经授权的效果示例、需要准备的材料、结果形态、支持设备、登录与费用条件、提供方、MakeNow 承接入口和可用状态。它可以被作品、教程、专题引用；引用不复制应用内容或另建一个应用。应用不以公开底层工作流为成立条件，也不让工程复制成为普通工具使用的前置步骤。

**执行统一由 MakeNow 承接。**社区应用详情只提供经核验的对应工具入口及使用条件；简单表单和复杂画布均按实际设备能力进入 MakeNow。社区不接收应用输入，不提供应用报价、任务提交、进度或结果页，也不建立第二套生成记录。入口需定向到对应工具或项目；生产深链接、登录后返回、设备适配和跨端身份仍待实现与核验。

访问详情、登录、预览和打开 MakeNow 不触发生成或扣费；提交必须由用户在 MakeNow 主动确认。

目标路径为社区应用详情 → MakeNow 指定工具或公开项目 → 在 MakeNow 输入、确认费用、执行、查看和找回结果。目标失效时说明状态并保留返回原社区详情的方式。外部执行结果未接通回流前，不能声称已自动进入社区“我的生成记录”。

### 2.2 提交、计费与任务状态

应用参数校验、动态报价、账户余额、提交、扣费或结算、取消、异常重试、任务状态与结果历史均由 MakeNow 按其实际规则提供，并在该侧完成验收。社区只准确说明可能需要 MakeNow 账号及费用，不写死动态价格，不预占或扣除社区积分，不展示未经同步核验的任务状态。两端账户与余额不因跳转或账号关联而自动互通。

MakeNow 的具体价格、失败处理、取消能力、结果保留期限及手机操作尚待逐项验证，社区文案不得将预期规则写成现有能力。应用失效时社区暂停使用入口，保留合法且仍有价值的介绍，不自动换工具。未来电商 Agent 仅作为后续规划，不进入当前可用名单、入口或计费路径。
### 2.3 主动发布与结果去向

结果先属于本人私有制作记录。下载只取得文件，收藏用于找回公开内容，发布才创建公开作品；三个动作不得合并。发布时用户选择具体文字、图片或视频结果，检查预览、补充标题和说明，确认是否展示输入、Prompt 或制作过程，并主动提交。未选择的原始输入、历史任务、画布素材不随结果公开。发布成功形成一个新作品身份与独立评论；若需审核，作者先看到审核中而非公开成功。发布失败保留编辑内容和关联结果，重试不重复建作品。

**结果与来源回流。**MakeNow 工具回流需核验身份、用户选定成果及稳定来源，只有拿到可信记录才显示系统验证的应用来源。复制项目生成的作品按已确认规则保留项目原作者、实际复用版本；不能因为用了同名工具就推断复制了某工程。无法验证的外部制作可由作者声明工具，但与系统记录分开展示。回流中断时保留 MakeNow 私有结果，用户可重新发起；未确认成功前不自动创建公开作品。

## 3. MakeNow 工程分享、复用与衍生

### 3.1 三档分享、版本和复制

作者在 MakeNow 私人工程上主动选择共享范围：仅分享成果时社区作品可读但工程不可查看；允许查看时访客只能查看所选公开版本；允许复用时访客可在查看后主动复制成自己的项目。查看、复制均按最新权限校验，隐藏按钮不能代替访问控制。复制者不能改原作者工程，作者不能借原工程更新覆盖别人副本。公开作品与独立资源可分别存在；一份工程可以被多个真实内容关联，不必为每篇说明复制工程对象。

公开时作者看到对外可见的版本、素材与依赖范围，确认哪些内容有权开放。日常私人编辑不改变公开版本；主动更新公开版本后，新访问按新版，既有作品的真实复用版本及已复制项目不被改写。历史公开版本是否还能由普通用户访问不预设；来源记录仍保留实际版本。作品可先仅分享成果，工程条件补齐后再主动开放。

关闭工程分享或降档时，后续查看/复制立即按新权限停止；若仅收紧至查看，停止新复制。撤下某件社区成果时，该作品不再公开且该作品上的关联工程入口停用，不据此关闭同一工程在其他独立作品、教程或资源上的有效分享入口；若工程本身关闭分享，则所有指向该工程的入口都按新权限停止。已获个人副本保留，首次开放复用时作者须被提示此后果。违规侵权处置与作者主动撤回分开，不能用“副本保留”阻止必要的平台处置。原工程或作品撤回后，衍生作品仍可保留自身合法成果，但来源入口显示不可访问，不显示私人节点、素材、会话或缓存预览。

### 3.2 衍生工程的授权链

“允许衍生工程再次分享”仅是“允许复用制作项目”的附加选项。默认仅允许复用者修改个人副本并发布合法成果，不允许公开副本工程；原作者主动开启后，复用者仍须主动选择公开版本、分享档位和向下游开放的范围，保留来源。工程可复制不等于其中素材可再分发，成果展示许可须另核。

多级衍生逐级显式授权；下游不能扩大任何上游许可。公开某级工程时，须核对取得该副本时适用的全部上游许可链。任何一级只允许创作时，该副本不得再公开工程，但可按素材许可发布成果。许可收紧仅影响此后新取得的副本；已有副本按取得时的有效许可保留资格，已合法公开的衍生工程不自动下架。后续查看与复制仍须符合该工程作者当前分享设置及既得上游许可。首次开放复用时向作者说明既有合法授权不会因原工程撤回而终止；违规与侵权处置另行处理。授权文本及实际能力待落实。

工程查看、复制、公开版本及衍生许可由 MakeNow 执行；社区维护内容展示与关联，不另设工程权限。社区定向入口须同时满足来源内容公开、关联有效和工程版本当前允许访问。来源撤回时，该处旧链接及缓存入口停用；其他独立合法内容或工程直达入口各按自身权限判断。来源记录保留但不展示已撤回内容；无法可靠校验权限时停止受影响的访问或复制。
## 4. 社区与 MakeNow 的跨产品承接

**身份衔接。**双端各自登录，首次将私人结果回流社区时，展示两端当前账号，由用户明确确认关联后再承接结果。公开浏览不强制关联，是否需要登录仍按目标工程访问权限判断；在 MakeNow 复制和制作使用当前 MakeNow 账号。已有有效关联时不反复要求确认，但每次私人回流均核验当前两端身份与结果归属。未关联或无法确认身份时保留允许的公开阅读及 MakeNow 本地操作，不把私人结果或副本自动归入社区账号，不凭相似昵称或邮箱合并项目、历史与成果。切换账号或关联失效时暂停旧身份回流，清理相关私有预览，不删除原账号资产。账号关联不代表积分互通，两端消费账户各自独立；具体登录、关联及身份校验能力仍待核验，不宣称已实现单点登录或数据迁移。

**定向与返回。**从社区打开应用或项目，目标页应带用户去指定工具、指定公开版本和允许的操作；登录后返回同一目标并重新核权限。目标不存在、已过期、已撤回或无权访问时，说明真实原因并给回原社区内容的路径，不能跳 MakeNow 首页造成误导。手机查看工程摘要和作品，PC 承接复杂编辑；跨设备提供复制定向链接的承接，具体目标与权限仍需实测，不承诺自动传素材或跨设备同步编辑。浏览器返回应回原内容与原浏览位置；跨产品返回能力需实测，未通过时以清楚的返回入口补足。

**回流与重复发布。**用户从 MakeNow 选择结果回社区时，先核对两边身份和结果归属，打开社区作品草稿而非直接公开。网络重试、双击或登录回跳只应恢复**同一次发布动作**；该动作成功后定向到对应作品或审核状态，不因重试建第二件作品。用户可以从同一制作任务重新主动选择不同成果，或为同一成果另行发起明确的新作品发布；新动作有自己的预览、确认与作品身份，不能因任务或来源相同而被永久去重。若回流失败，MakeNow 私有结果仍可从其原位置找回，告知重试方式；项目来源和应用来源分别带入真实记录，不能靠页面 URL 猜测。

切换账号、解绑或关联失效时，清除当前设备旧身份的跨端缓存与预览，不迁移或删除原账号的项目、作品和已保存草稿；重新登录后仍按实际权限及保留期限找回。自助解绑入口是否存在待核验。

从活动进入 MakeNow 时保留本次活动关联，回流作品编辑展示原活动及其要求。提交前重新核验截止、资格和锁定；活动失效时保留私有结果与编辑内容，不自动投稿。若允许普通公开，需用户明确选择取消本次活动关联后按普通作品流程提交，不能静默改成普通发布。已接受的活动评审材料仍按活动规则，作品审核通过不等于活动资格通过。无法可靠带回活动身份时，提示返回原活动继续操作，不靠活动名称猜测或绑定到另一活动。

## 5. ComfyUI、资源与运行应用

ComfyUI 工作流作为可导入、查看、继续编辑的文件或工程时是**独立资源**；资源详情需明确效果或工程预览、适用版本、节点/模型/素材依赖、取得方式、提供者、展示与复用许可、设备要求和维护人。用户取用资源不等于已经在本站运行，也不因资源可下载就自动创建 AI 应用。若有人把它封装成明确输入、输出、可执行入口且落实实际执行维护与成本责任，才另建 AI 应用并以有依据的关系关联该资源；底层资源可以不公开。

**ComfyUI 能力边界。**本期按资源的真实取用条件展示，不承诺MakeNow 能直接导入、运行每份 ComfyUI 工程；仅对逐项实测兼容且有维护人的候选再决定是否做应用化。本期不建设通用兼容与自动部署平台；工作流可先作为资源发布，不必等应用化。当前无兼容、安装、部署或运行成功证据，文案不得写“导入即用”或“自动应用化”。

资源阅读、取得和执行分别验收：读者可看真实条件；有许可者按说明取得对应版本；无许可、文件失效或依赖缺失时有明确状态；手机可阅读详情，但复杂导入/调试引导 PC；对选择“运行应用”的用户，必须能在 MakeNow 走完输入、费用、任务和结果闭环，不让下载文件代替运行能力。

## 6. 应用与资源供给的上线前逐项核验

每一候选单独建核验记录，先按真实对象分类，再决定公开介绍、可用入口与推荐。最低上架要求：未核验候选只留内部草稿或研究材料，不以公开“纯介绍”充当可用应用占位；已公开且后来失效的应用可保留有价值的合法介绍，同时暂停运行入口并说明状态。已知官方工具可优先登记，仍须核验；创作者工作流可先作为资源独立发布，不因尚未应用化被阻塞；第三方可运行服务不默认为官方托管，也不自动并入社区计费。首发应用名单待逐项核验。

| 核验项 | 每项必须留下的判断；未满足时的处理 |
| --- | --- |
| 对象与任务 | 是作品、资源，还是实际可运行应用；应用要有单一明确任务、输入、输出和目标用户。不能用功能介绍代替运行能力 |
| 归属与许可 | 提供者、真实作者、平台展示/分发/复用许可、工程内素材及模型依赖许可，区分公开成果与公开工程；不清楚则先不开放相应范围 |
| 责任人 | 内容编辑、能力维护者、权限/费用核对人及更新通知路径；可以兼任，但不能空缺后上架 |
| 效果与条件 | 可公开且经同意的示例、输入限制、输出形态、失败边界、依赖/版本、额外账号和有效入口；缺材料可留草稿，不宣称可用 |
| 积分与费用 | 核验 MakeNow 的实际报价、扣费、失败与取消规则；社区仅说明账号与费用条件，不执行应用计费；真实能力仍须逐项验证 |
| 设备 | 在支持的手机/PC 上分别走实际操作，确认上传、输入、费用、结果、返回；只看响应式页面不算操作可用 |
| 端到端 | 使用获准测试条件走详情→MakeNow 定向入口→费用确认→提交→进度→成功/异常→找回→主动发布及来源，记录证据、失败项与复测结论 |
| 更新与失效 | 明确版本变化、引用影响、暂停运行/取用、恢复核验及推荐入口处理；保留合法可读内容，但停止误导性的“立即使用” |

首发及推荐仅从逐项核验通过的候选中选择；未通过者维持内部草稿。

## 7. 验收重点

- MakeNow 执行逐项核验报价、账户、任务归属、失败与结果找回；社区不承接应用扣费或任务记录。
- 工程公开版本、查看、复制及多级衍生按当前权限与取得副本时的有效授权链校验；旧链接和缓存同样受控，已获合法副本不因后续收紧而自动删除。
- 私人结果回流核对双端身份及归属；切号或解绑停止旧身份回流并清理当前设备私有预览。登录后返回指定目标；同次发布重试只产生一个作品，主动新发布另计。
- 活动期间制作的结果回流保留原活动关联，提交前重新核验截止、资格和锁定；失效后不自动投稿或改成普通发布。
- ComfyUI 资源须核版本、依赖和许可；只有有明确执行入口、费用和维护责任且逐项验证的候选，才可作为 AI 应用。

## 8. 待落实事项

MakeNow 实际价格与结算规则、任务查询及取消能力、生产定向链接、双端身份关联与权限同步、手机操作、ComfyUI 兼容性及首发应用名单仍待真实服务与测试条件核验。未通过核验的候选不展示为可运行应用。


### 社区界面承载边界

社区共用页面暂移除关联账号与选择成果，不把未接入的身份确认、成果回传模拟成常规产品路径。上述身份、权限、去重和活动关联规则作为后续接入约束保留；待实际链路核验后，在 MakeNow 发起回传的位置选择成果，社区承接本人主动发布，是否另设关联确认界面依据实际身份体系确定。手机访问电脑专属应用使用详情内轻弹层复制链接，资源详情保留工程或素材的版本、内容、使用条件与复制许可说明，由作品或教程关联进入，不新增资源频道。
