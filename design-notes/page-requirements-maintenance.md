# 阅读台页面需求维护

阅读台的“页面需求”按页面标识读取以下文件：

- `page-requirements-c.json`：C 端页面。
- `page-requirements-b.json`：B 端页面。
- `page-requirements-cross.json`：跨产品页面。

每项描述当前页面的职责与设备差异、字段与限制、动作前置和结果、状态变化、输入异常与恢复、B 端维护影响及可逐条核查的验收。并列字段和状态使用表格；验收使用编号列表。待明确条件使用稳定编号，不写成已具备能力。字段限制、权限、失败恢复及上下游身份关系不能因精简而删除。

修改记录、开发实现、验证过程、样例运行说明和像素参数不进入页面需求。C 端公共规则 G01–G08 维护于 `c-requirements-20261005/common-rules.md`，同步同目录 JSON 用于页面内折叠展示；每页仅补业务差异。完整交付稿由当前页面 JSON、公共规则及 B/C 联动清单汇总，不另行手工维护一份页面正文。`requirements-*.md` 保留为模块背景资料，不再由阅读台切片或整段回退展示；与最新页面需求冲突时应同步清理旧表述。

新增页面需同时补充相应标识；运行 `node scripts/validate-page-requirements.mjs` 检查注册覆盖、重复整页内容、标题结构及过程性文字。共享需求变化还须核对关联页面业务规则；脚本通过不替代语义与浏览器检查。
