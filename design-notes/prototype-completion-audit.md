2026-09-27。范围仅为本研究站的 C 端、B 端和跨产品交互原型。沿用已确认的白色首页、移动端五栏、PC 最大 1800px、4px 卡片圆角。真实社区、后台与 MakeNow 未修改或发布。

## 页面与阅读方式

C 端 42 个页面标识；B 端 31 个页面标识；跨产品 18 个标识，其中 1 个为说明页。会员与用户举报范围均已取消。商城记录在 PC 以商城弹层呈现。

阅读台统一提供页面原型、页面需求、模块流程；C 端可切换手机和 PC，正常页与业务状态分开展示。PC 首页与子页共用导航，正文按列表、阅读、表单、个人管理组织；预览比例只改变阅读台画布。页面需求直接引用现有需求正文，流程可打开关联页。产品内导航更新阅读台当前页。

| 范围 | 补全内容 |
|---|---|
| 首页、专题 | 展示位按发布版本和设备读取；专题关联同一公开对象；列表与详情双端版式 |
| AI 应用 | 当时原型覆盖用途、筛选和社区输入/积分/任务/结果模拟；后者已退出现行需求。现行社区只展示与介绍，MakeNow 承接输入、费用、生成、任务和结果；生产定向与回流待核验 |
| 社区、圈子 | 多帖推荐/最新、分页与返回保留；加入/退出和个人关系找回；关闭后停止发现和新发布，原帖独立保留 |
| 教程、作品、资源 | 公开状态守门；作品文字/图片/视频；教程和资源独立维护、相互引用；手机阅读、PC 制作承接 |
| 搜索、作者 | 分组、多对象、加载更多、固定栏目；按公开权限过滤；同一内容进入同一详情 |

| 既有业务 | 活动、积分、签到、邀请、商城和兑换记录沿用已有边界；本次不包含会员能力 |
| B 端 | 草稿与公开版分离；审核不擅自恢复下架内容；运营编排、引用、核验、交接、记录及相关 C 端状态 |
| 跨产品 | 公开版本、查看/复用权限、复制幂等、作者维护、结果确认和主动回流；回流不自动发布 |

实现细节与边界分别见[内容消费](content-flow-completion.md)、[个人与既有业务](personal-flow-completion.md)、[B端与跨产品](b-cross-completion.md)。

## 验证口径

[逐页检查记录](retained-evidence/completion-page-check.json)是移除会员页前的历史检查记录，涵盖当时 42 个 C 端子页、33 个 B 端页、18 个跨产品页及选取的异常状态。当前页数以本页清单为准；正常渲染与无横向溢出只证明页面可读，不代表全部业务分支已经验证。

当前范围核验：C/B 页面清单、个人入口和阅读台流程已不包含 `benefits` 或 `op-members`；当前需求与交付入口明确取消会员，商城兑换和积分仍保留。`npx tsc --noEmit` 与会员改动文件的定向 `oxlint` 通过。历史逐页检查记录未重新生成，不作为移除后的页面渲染证明。

本轮点击验证涵盖：社区排序/分页/返回、不同帖子身份、输出类型筛选、评论登录恢复且不自动提交、圈子加入到个人关系、活动帖子草稿与投稿、应用积分与结果编辑、B 下架/恢复到 C 旧链接、MakeNow 仅查看阻止复制及结果确认回流。后续发现的修复与复测统一记录于 [验证记录](../design-qa.md)。
