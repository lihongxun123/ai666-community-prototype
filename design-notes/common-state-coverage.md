# C端通用状态规范与覆盖

入口：`/community-options/prototype-review?section=c&view=common`。

当前有 11 组、53 个代表样本。它们定义共用呈现与恢复规则，不替代每个业务的资格、审核、积分和任务状态。样本仅展示内容区域；业务页面沿用原有导航。

## 分类与适用范围

| 分类 | 样本数 | 适用范围 | 恢复与操作规则 |
|---|---:|---|---|
| 加载骨架 | 17 | 首页、不同列表、内容详情、圈子/作者/活动/我的 | 按内容结构占位；局部刷新保留已加载部分；不把整页都换成骨架 |
| 空内容 | 5 | 无内容、首次无资产、搜索/筛选无结果、详情容器内无内容 | 保留关键词或条件；清除条件、继续浏览、创作等动作按业务提供；空内容不等于下架 |
| 加载与媒体异常 | 8 | 初次读取、加载更多、到达末尾、图片/媒体和关联内容 | 可重试范围限定在失败部分；已加载正文和有效互动不连带消失 |
| 输入与操作反馈 | 5 | 字段校验、上传、提交、失败及成功反馈 | 输入就近校验；提交防连点；失败保留输入；用户主动重试；成功轻提示不抢焦点 |
| 登录与身份 | 3 | 未登录、登录过期、账号切换 | 仅在需要身份的动作触发登录；登录后恢复位置与输入，不自动提交；账号切换不将原账号私有草稿带给新账号 |
| 权限与访问 | 3 | 无查看权限、无操作权限、仅可查看 | 无查看权限不泄露正文或内部原因；无操作权限保留可读内容和当前输入；只读不提供编辑/复制/执行入口 |
| 内容与能力 | 3 | 内容下架或不存在、资源授权撤回、应用暂停 | 内容不可访问给返回入口；资源撤回不删除关联教程；应用暂停停止新任务，保留介绍和已有记录 |
| 编辑保护 | 3 | 未保存离开、保存失败、版本冲突 | 继续编辑/保存/主动放弃分开；保存失败留在当前页；冲突不覆盖新版本，可查看新版本并保留本次修改 |
| 结果待确认 | 1 | 已发出写入请求但结果未知 | 查询原请求或记录；不提供直接重新提交、不擅自认定失败/退款；未能查明时仍保持待确认 |
| 设备与跨端 | 2 | 手机不支持编辑、复制链接失败 | 详情可浏览；实际画布/工作流引导电脑端；链接允许手动复制，不能自动创建或公开项目 |
| 网络与服务 | 3 | 断网、读取超时、服务暂不可用 | 不自动重发写入；保留已加载内容与未提交输入；读取可手动重试；写入超时进入结果待确认；不承诺恢复时间 |

## 规则优先顺序

1. 先判断身份、查看权限与内容是否可访问，再决定是否展示正文；不能短暂暴露受限内容。
2. 整页数据未到达时使用骨架；已有数据的局部失败只影响相应区域。
3. 阅读可用而编辑/运行不可用时保留阅读，停止对应操作；不将暂停当作下架。
4. 提交已经发出且回执未知，优先查询原请求；只有明确未受理或明确失败，才依据业务规则允许重试。
5. 登录恢复、网络恢复、返回前台均不代表用户授权再次提交。输入保留仍受账号隔离、内容权限与业务有效期约束。
6. 操作过程中发生账号切换，停止使用原账号数据和提交上下文；不能将未完成结果绑定到新账号。

## 页面映射与评审规则

- 首页使用专用骨架；专题使用大图列表；AI应用/商城用双列；社区用帖子流；教程/圈子/搜索/个人资产/通知/记录用图文或记录行；活动中心用活动卡片。
- 专题、作品、帖子、教程、AI应用、资源、圈子、作者、活动、我的分别提供对应内容骨架；原型实际 loading 使用同一实现。
- 只收起有明确映射的 loading，以及专题列表空内容/读取失败和专题详情读取失败。其他 empty/error/failure 不按名称隐藏。
- 登录、权限、应用暂停、编辑冲突和结果待确认等虽有通用规则，仍保留在业务状态板以核对上下文。
- 积分不足、报价变化、审核退回、活动资格/结束、生成排队/结算、授权复制与跨产品身份不合并成通用错误。

## 证据与实现边界

登录过期、账号切换、权限限制、下架、暂停、保存失败、冲突、结果待确认和电脑端引导，在现有业务原型已有场景。本轮统一规则并新增独立演示，尚不代表全部业务页已改为共用组件。

网络/服务组是本轮新增的建议交互规范：尚无真实网络检测、超时策略或服务状态接口。样本不会联网检测，也不会承诺网络已恢复。恢复时间、请求超时阈值、草稿保存期限和服务错误码由后续研发方案确定，本轮不虚构数值。

身份按钮明确为“模拟登录完成/模拟返回原账号”。输入、保存和上传演示仅在当前样本内存中；冲突副本仅保留在本页，不代表持久化草稿。真实业务的跨刷新保留、登录回跳、幂等受理和权限隔离仍须研发联调验收。

## 验收要点

- 已登录且有权限的正常内容不被通用错误遮盖；受限正文不泄露。
- 登录恢复后不会自动提交；切换账号不呈现原账号未完成内容。
- 保存失败保留文字且不离开；版本冲突不会覆盖新版本。
- 结果待确认只能查询原请求/记录，查询失败仍保持待确认。
- 断网/超时/服务异常不会反复发送请求，也不会把待确认写入当作普通读取重试。
- 手机可阅读介绍，不能误入实际画布编辑；复制失败有手动复制入口。
- 通用样本无业务顶部/底部导航，业务模块的状态与恢复路径仍能单独评审。
