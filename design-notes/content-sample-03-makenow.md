# 样本 03：MakeNow 项目在社区的展示与维护

日期：2026-09-25｜展示顺序已确认；具体字段与实现仍待深化，非正式页面定稿、发布授权或接口验收

已确认：社区按“成果预览 → 用途说明 → 制作方法 → 关联工程 → 复用条件”组织本类内容，按需展示可选区域。用户认可该结构同时为 MakeNow 导流：用户先在社区理解内容，再按权限和设备条件进入对应项目查看或复用。此确认不把工程开放或跳转设为每件作品的必选项，也不改变移动端复杂操作转 PC 的边界。

## 样本与对象

样本采用 MakeNow 首页公开案例“母亲节主题短片”。已只读查看作品弹层及[关联画布](https://www.makenow.tv/case-share/6/canvas)：画布包含故事输入、角色/场景描述、参考图、智能分镜及节点连线，并有“复制画布到我的新项目”入口。视频播放完整性、生成与复制结果未验证。本文件不搬运媒体或私人项目材料，不推定该案例已授权在社区发布。

本样本以一件视频作品为社区主内容，关联一个独立的 MakeNow 项目资源。制作说明是作品附加说明；只有另有完整教学材料时才建立独立教程。项目的存在不自动产生一条 AI 应用，也不要求额外发帖或建专题。以下为目标呈现与维护建议；分享、版本及回流权限沿用[已确认内容模型](site-content-model.md)。

## 社区阅读样本

| 展示位置 | 本样本如何呈现 | 材料和边界 |
| --- | --- | --- |
| 成果区 | 标题“母亲节主题短片”、视频、作者、作品说明；下接评论与互动 | 标题及视频入口已见；上线媒体、署名与公开许可需供给方确认；不编造播放量或评价 |
| 用途说明 | 建议表达：供了解故事如何组织成角色、场景和分镜的人参考 | 编辑建议，需作者核对；不宣称适合所有故事或保证一键成片 |
| 制作方法摘要 | “故事输入 → 角色与场景整理 → 参考图 → 智能分镜” | 来自所见节点结构，只是结构摘要，不是已验证的执行顺序或完整教程；成片剪辑过程未核实 |
| 关联工程卡 | 项目名称、MakeNow 标识、工程预览、公开版本、查看/复用权限、设备条件、入口 | 当前案例有对应画布；社区资源身份、公开版本机制和权限映射仍需开发；不把完整节点图嵌入手机内容流 |
| 复用条件 | 需要准备的材料、哪些素材允许复用、模型/工具依赖、运行费用提示、已知限制；是否允许衍生工程再分享 | 本案例完整条件未核验，正式开放复用前由维护者补齐；不能用“有复制按钮”替代条件核验 |
| 关联教程（可选） | 有独立教程时展示引用卡，没有则不显示该区域 | 不用空占位要求作者凑齐教程 |

PC：允许查看时提供“在 MakeNow 查看项目”；允许复用时另提供“在 MakeNow 复用项目”，复制确认与执行由 MakeNow 承接。打开页面不自动复制或运行。复制不能编辑原作者工程。

移动端：保留成果、说明、讨论及工程摘要；复杂工程操作提示使用电脑打开 MakeNow，并提供复制链接的引导。不预设跨设备自动传图或同步任务。仅分享成果时不显示可打开工程的入口。

这是一件作品关联一项资源，不新增“项目作品”内容类型。项目资源可以被其他作品或教程引用，引用同一身份而非复制工程。最新已确认口径：资源经内容关联进入社区独立详情，不新增固定资源频道、列表或搜索类型；工程操作到 MakeNow，具体字段与接口仍待细化。

## 需要维护的信息及责任

| 信息组 | 社区后台/后续作者入口的目标职责 | MakeNow 的目标职责（实现待核验） | 本样本准备程度 |
| --- | --- | --- | --- |
| 作品内容 | 标题、简介、成果媒体及顺序、封面、署名、适用分类 | 提供作者选定的结果，不能把全部工程素材自动公开 | 有公开展示线索；社区发布素材和许可待补 |
| 方法说明 | 目的、准备条件、关键步骤、限制；独立教程通过引用关联 | 提供经作者选择的过程素材 | 有节点结构摘要；实际过程说明待作者核对 |
| 项目资源 | 资源身份、简介、预览、维护人、与作品的关系 | 工程、稳定项目标识、公开版本标识、定向查看/复用入口 | 已见指定案例画布；跨系统标识与版本接口待核 |
| 分享权限 | 展示当前有效权限，后台治理可停止公开入口 | 执行查看、复制、工程再次分享的权限校验；作者设置必须与社区一致 | 三档及衍生选项已定；权限保存的唯一归属与同步接口待定，禁止两端各存一套可冲突开关 |
| 复用条件 | 向读者展示材料要求、依赖、适用许可和限制 | 校验实际依赖与运行条件，运行前提供真实费用信息 | 完整依赖、素材复用许可、费用口径待核，不填写猜测金额 |
| 版本与可用性 | 显示公开版本、入口可用状态与必要更新说明 | 私人工程与公开版本分离；执行复制、运行及失败反馈 | 已确定主动更新规则，实际快照实现待核 |
| 来源关系 | 新作品展示来源项目和原作者，维持独立评论 | 复制时记录来源及版本，发布成果时传递关联 | 产品规则已定，接口待核；不靠作者手填身份 |
| 内容治理 | 预览、发布、独立审核、下架和关联入口处理 | 按治理结果落实受影响的项目访问限制 | 具体状态映射与跨产品一致性待设计 |

前期复杂内容由官方后台整理维护，后续作者入口维护同一对象。后台维护公开内容不代表编辑可以直接改写 MakeNow 私人工程。成果允许公开与工程/素材允许复用须分别确认。

## 生产与消费路径

1. 作者或供给方选定成果，补齐作品介绍，按需选定要开放的项目版本和素材；不要求每件作品都开放工程。
2. 社区编辑整理作品与资源介绍，维护者确认工程与复用条件；缺少完整方法时先不创建教程。
3. 发布前预览实际可见范围，落实三档分享权限和衍生工程选项。作品达到发布条件但工程条件未齐时，可先仅分享成果，不能假装项目已可复用。
4. 访客在社区看作品、读方法、讨论；有权限且在适合设备上时，进入 MakeNow 对应公开项目查看或确认复制。
5. 复用者在个人副本制作，主动选择结果并补充说明后发布为新作品，保留来源关联；个人副本不随成果自动公开。

## 必须呈现的异常状态

| 情况 | 社区承接 | MakeNow 承接 |
| --- | --- | --- |
| 原作者仅分享成果 | 正常展示作品，不提供工程入口 | 不因作品公开而开放私人工程 |
| 从允许复用收紧为仅查看 | 保留查看入口，停止新复制 | 校验最新权限，不仅依赖社区按钮隐藏 |
| 工程分享关闭 | 成果仍可读，原工程入口说明已停止分享 | 旧链接不能绕过访问限制；已获个人副本按已确认规则保留 |
| 运行依赖缺失或暂不可用 | 不承诺可运行，展示维护状态；可读内容按原权限保留 | 给出具体阻塞原因，不静默扣费重试或擅自替换执行方案 |
| 作者工作中工程改变 | 继续展示已发布版本 | 原工程编辑不自动覆盖公开版本 |
| 原分享撤回后的来源访问 | 新作品保留来源关系并显示来源不可访问 | 不透出撤回的原工程 |

## 本轮待确认与后续验证

“成果预览 → 用途说明 → 制作方法 → 关联工程 → 复用条件”的展示顺序已确认，不重投已确认权限。不是每一项都成为必填：仅成果作品不要求填写工程字段，方法摘要可选，开放工程才需要对应的预览、权限、版本及使用条件。

画布、工作流、模板脱离成品作品独立发布已确认：提供效果示例或工程预览、用途、使用条件和明确维护人，不强制先发作品或教程。此样本展示“作品关联资源”的一种组合，不限制资源独立成立；社区详情与制作侧工程操作的分工已确认，详细流程与待确认项见[原型前需求评审](product-requirements-review.md)。

后续需确认多级衍生授权/授权改变的影响。接口核查覆盖身份衔接、公开版本、权限执行、复制来源和结果回流；目前未验证这些接口，也未完成真机验证。
