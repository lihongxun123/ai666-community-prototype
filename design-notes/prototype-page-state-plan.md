## 1. 既有样本边界与依据

本轮先完成**一个端到端原型样本**：官方后台编辑教程并引用一份**已有公开资源** → 手机发现和阅读教程 → 查看资源详情及设备要求 → PC 上的 MakeNow 模拟承接 → 选择成果回流社区私有作品编辑 → 本人预览并显式提交，看到模拟的待审结果。实际样本位于 `public/research-walkthrough/tutorial-loop.html`、`tutorial-loop.js`；它不包含完整资源新建/发布、全站教程列表、真实账号或工程运行。样本中的人物、内容、版本、项目与成果均为虚构演示；不声称真实运行、积分扣减、工程复制、身份互通或内容发布已接通。

此 `site` 是白色研究站的改版研究与原型环境，延续本站白底、黑白灰导航与品牌 Logo、PC 最大 1800px 的既有方向；它不是外层深色生产 C 端/B 端原型，也不恢复外层已废弃的白色聚合内容版。研究站原型和真实仓库分别验收。本表引用已确认需求，不另定菜单、业务对象或新的权限。

规则来源：[原型前需求集中评审](product-requirements-review.md)；[C 端消费与个人管理](requirements-c-flows.md)（下称 C）；[内容生产与 B 端维护](requirements-b-content.md)（下称 B）；[应用执行与跨产品互通](requirements-cross-product.md)（下称 X）。需求中“已确认”指产品规则，不代表现网能力。特别保留五类内容对象、移动端五栏、教程与资源独立维护、后台正式发布、MakeNow 独立工程权限、私有回流与活动关联规则（集中评审 §2–4、§7；C §0；B §3–5；X §3–4）。
