# 多元拾光研究室

2026-09-19 发布整理：/community-options/presentation 为九屏方案演示；/research-status 为统一证据状态，/research-decisions 为九主题方向与供给判断。推荐组合以实践为主线、创作交流独立，首版暂缓专业服务撮合。研究判断与方案假设分开呈现，早期机制材料按来源时点使用。

[在线研究总览](https://ai666-community-research-20260908.hongxun-li.chatgpt.site/#overview)

研究以周活用户数为主要指标。资料按各自观察日期使用，候选方向与试点计划不代表已经执行。

持续活跃研究接在现有方案页与主报告中：`lib/retention-research.json` 保存方向比较及当前研究范围；`lib/retention-evidence.json` 保存20条回访与维护记录，其中9条新收录、11条复核，不作为20个独立用户。`lib/desk-comparison.json` 保存三组同任务比较：一组已登录浏览器操作，两组公开材料审阅。输入、读取范围及产品条件差异单独保留，未测试生成效果或真人学习结果。

供给演练、招募、供稿和四周观察由团队人工控制，不列入代理待办。试供与观察的安排仅在折叠参考区保留。当前公开研究记录见上一级 `desk-comparison-2026-09-14/`，此前材料保留在 `retention-comparison-2026-09-14/`。

## 阅读结构

| 入口 | 内容 |
| --- | --- |
| 研究总览、竞品调研报告 | 研究范围、五类平台、内容路径、供给与商业机制 |
| 竞品档案 | 五类15个平台，按类别查阅 |
| 行业与用户 | 行业结构、用户任务；全国规模、使用与付费数据作为详细依据 |
| 内容需求与社媒生态 | 六类消费任务、连载路径、平台承载、评论与供给判断 |
| 竞品研究专题 | 用户、内容、运营、商业、访问与渠道、样本及经营证据 |
| 方案与验证 | 借鉴建议、候选方案、供给合作、MakeNow能力与验证计划 |
| 证据与资料 | 内容和互动样本、经营与使用证据、来源方法 |

专题入口与15个平台hash保持兼容。平台目录只按类别分组；专题按用户、内容、运营、商业、访问、样本、工具和证据组织。

## 文件职责

- `lib/`：当前研究正文、指标、来源和平台档案。
- `components/`：阅读结构与页面呈现；导航名称集中在 `lib/research-navigation.ts`。
- `public/research-kit/`：研究数据、材料与图片，页面不再提供下载或资料包入口。
- `public/research-images/`：已整理的证据截图。
- `public/research-deliveries/`：有明确日期的冻结汇报版，保留当时内容。
- `.openai/hosting.json`：现有Sites项目，不新建替代站点。

## 编辑与同步

一个问题确定一个主要页面，其他页面用短链接引用。长页先给比较和判断，再按主题查档案；原始样本、方法与历史检查放到明确的附录。数字、日期、来源、未验证状态与原始引语不随文风修改。

当前与历史材料不互相覆盖。上一级 `editorial-architecture-2026-09-13/` 保存审校清单、编辑说明、下载同步及验证脚本；`export-map.md` 标明旧生成器会覆盖哪些当前数据。不要为更新下载而直接运行历史组装脚本。

发布在本独立仓库中完成。只提交明确文件，保持当前公开访问范围；不涉及真实社区、管理后台、MakeNow和API业务系统。

本地启动：`npm run dev -- --host 127.0.0.1 --port 3000`。构建：`npm run build`。
