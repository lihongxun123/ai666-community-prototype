在本仓库迭代页面和研究正文，引用具体来源并保留证据日期。独立交付版从已核对内容生成，更新后重建附件清单和ZIP；不要修改已冻结的历史交付。当前站点和独立汇报共用同一份研究结论，交付版另保留可离线阅读的文件结构。

发布前检查本地链接、资源引用、敏感信息和下载包；按明确路径暂存并提交本仓库文件。使用同一Sites项目，推送确定的Git提交，在该提交的独立工作目录中构建，打包构建结果并保存、部署版本。上线后以匿名HTTP访问验证主站、独立报告、附录和下载文件。
