# 多元拾光研究室

[在线研究总览](https://ai666-community-research-20260908.hongxun-li.chatgpt.site/#overview)

研究以外部目标用户的持续有效活跃为目标。资料按各自观察日期使用，候选方向与试点计划不代表已经执行。

## 阅读结构

| 入口 | 内容 |
| --- | --- |
| 研究总览、竞品调研报告 | 研究范围、七组比较与证据覆盖 |
| 竞品档案 | 五类18个平台，保留平台对照 |
| 用户与市场 | 中国AI用户、平台需求、商业模式、访问与渠道 |
| 内容与运营 | 内容形式、消费主题、平台运营与工具关系 |
| 方案与验证 | 借鉴建议、候选方案、供给合作、MakeNow能力与验证计划 |
| 证据与资料 | 内容和互动样本、经营与使用证据、来源方法 |

19个专题入口和18个平台hash保持兼容。平台目录只按类别分组；专题中的对照表可按页面筛选。

## 文件职责

- `lib/`：当前研究正文、指标、来源和平台档案。
- `components/`：阅读结构与页面呈现；导航名称集中在 `lib/research-navigation.ts`。
- `public/research-kit/`：研究数据、材料与图片，页面不再提供下载或资料包入口。
- `public/research-images/`：已整理的证据截图。
- `public/research-deliveries/`：有明确日期的冻结汇报版，保留当时内容。
- `.openai/hosting.json`：现有Sites项目，不新建替代站点。

## 编辑与同步

一个问题确定一个主要页面，其他页面用短链接引用。长页先给比较和判断，再按主题查档案；原始样本、方法与历史检查放到明确的附录。数字、日期、来源、未验证状态与原始引语不随文风修改。

当前与历史材料不互相覆盖。上一级 `editorial-architecture-2026-09-13/` 保存审校清单、编辑说明、下载同步及验证脚本；`export-map.md` 标明旧生成器会覆盖哪些当前数据。不要为更新下载而直接运行历史组装脚本。

发布在本独立仓库中完成。只提交明确文件，保持当前公开访问范围；不涉及真实社区、管理后台、MakeNow和API业务系统。

本地启动：`npm run dev -- --host 127.0.0.1 --port 3000`。构建：`npm run build`。

竞品和市场页面只呈现研究事实、分析及证据缺口；多元拾光的采用建议集中在“方案与验证”，通过研究依据链接回到原页面。当前调整与核验记录见上一级 `reader-focus-2026-09-13/`。
