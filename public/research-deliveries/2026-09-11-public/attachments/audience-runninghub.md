# RunningHub：用户画像与产品价值

[官网](https://www.runninghub.cn/) · 资料核查截至2026-09-10。群体占比均未取得，不由套餐、热榜或有限样本估算。

RunningHub 托管 ComfyUI 工作流，作者也可将流程封装为简化应用。公开记录中有初学者导入外部流程，另有潜在用户因显存不足考虑采用。运行后仍可能遇到模型缺失、节点兼容和结果整理问题；已记录的短流程尚未验证项目交付。

## 用户、供给与付款角色

| 角色 | 当前分析 |
| --- | --- |
| 消费与使用 | 直接运行应用，或把外部工作流导入云端的人；技术熟练度差异很大。 |
| 供给与维护 | 维护工作流、说明、外部教程和客户端的人；不能用发布数量代表全部用户。 |
| 付款与采购 | 个人运行订阅/资源购买者，与 API 集成付款者分别识别；购买会员不自动证明 API 权益生效。 |

## 相反证据与未决问题

- 云端可减少本地显存障碍，但外部流程导入仍有节点和模型适配；使用者实际求助抵消“完全零门槛”的理解。
- 原作者对用户提供帮助，却明确表示尚未建立RunningHub账号；不能把答疑者自动计作平台用户。

- 全部点是可区分公开账号/署名观察，不是已核实名人数；每项画像未达到5个一致独立点。
- 三端域名的人数去重、实际商用采用、批量成本、维护工时与作者收入未知。

## 后续最有价值的证据

- 跟踪同一已跑通流程是否处理第二批真实素材及是否采用，补5名一致任务的独立使用者。
- 补API问题的明确修复与使用者确认，分清会员开通、接口准入和资源消耗。
