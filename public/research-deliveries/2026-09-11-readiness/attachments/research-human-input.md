# 多元拾光研究：待补材料

填写已有情况即可；没有记录的字段写“未记录”，不能确定的写“待确认”。四组材料可以分次补充。请只提供匿名汇总、脱敏记录或可查看入口，不提交密码、密钥、用户联系方式。

## 1. 内容产能（E5）

用途：判断四种方案中哪些工作能持续承担，是否需要招聘或合作。

| 字段 | 请填写 |
|---|---|
| 能负责选题、制图/视频、文字编辑、工作流调试、答疑/点评的人 | |
| 每人可用于社区的每周小时数，与MakeNow研发的占用分开 | |
| 最近完成的一至三条内容：类型、制作起止、返工、审核、发布后维护 | |
| 没有生产记录时，现阶段实际能承诺的频率及依据 | |
| 可以外包/合作的工作；是否已有具体人选和报价 | |

最低材料：一份真实内容的制作记录、各角色可用时间。单次耗时只能建立起点，不能直接作为长期产量；有连续生产记录后再判断可维持频率。

## 2. 预算与成本（F5）

用途：计算每个合格交付的成本，判断补贴及维护是否可承担。

| 字段 | 请填写 |
|---|---|
| 预算覆盖的起止日期及总额/币种 | |
| 可用研发、运营、制作工时；现金成本与内部工时是否需分开 | |
| 代表模型的实际供应成本及计价单位 | |
| 失败扣费、退还、重试、存储/带宽的实际处理 | |
| 每月可承担的免费额度、活动补贴、作者合作费用上限 | |
| 收费收入如已有：实收、退款、通道费；没有则留空 | |

最低材料：阶段预算和工时上限、一个代表任务的真实费用记录。页面标价、账户积分和供应成本分别填写。

## 3. 完整任务及素材交接（G5）

用途：确认MakeNow/API能兑现什么交付承诺。当前仅确认一个画布的副本创建、文本保存重开；部分图片未显示，未完成生成与独立接收者复现。

| 字段 | 请填写 |
|---|---|
| 一项明确任务及合格条件，例如指定场景图的主体、尺寸、用途 | |
| 可使用的输入素材/来源/许可范围；已知可访问入口 | |
| 实际模型和可用测试环境；不需要提供密钥 | |
| 允许的生成次数（含重试）、额度来源、总费用上限 | |
| 如已做过：输入、关键步骤、结果、失败/修改、实扣与退款、耗时 | |
| 可接收材料并独立操作的人；是否已有复现结果 | |

最低材料：已有完整任务记录，或足以受控执行的范围和资源。补齐授权只能启动核验，不能直接把G5标为完成。接收者复现另记条件、失败点与结果。

## 4. 外部使用行为（H3）

用途：区分“平台在供给内容”与“外部用户有没有消费这些内容”，对方案采用条件提供依据。

| 字段 | 请填写 |
|---|---|
| 同一观察窗口：开始日期、结束日期、数据来源 | |
| 进入社区的外部访问者/账户数，去重口径与匿名访问覆盖 | |
| 来源：抖音、小红书、API、MakeNow、直接访问、未知 | |
| 内容查看、展开/播放、下载/复制/使用、提问/回应分别有多少 | |
| 至少第二次相关使用的人数；两次使用的定义及日期间隔 | |
| 可识别的平台运营/测试账号范围；无法区分者单列未知 | |
| 积分领取者是否还发生了上述行为；奖励结束后的行为如有 | |

最低材料：同一时间窗口的匿名汇总，或少量可追踪但去身份化的行为记录。不能识别第二次使用时保留未知；内容由运营发布，也可以产生真实外部消费。

## 补齐后如何继续

1. 先检查字段口径和缺失，不急于加总或外推。
2. 将实际时间、费用、交付结果和外部行为代入四方案条件，指出哪些承诺可以兑现、哪些必须缩小。
3. 对仍影响判断的具体问题继续调研；确认方向、招聘、合作联系和排期另外讨论。
