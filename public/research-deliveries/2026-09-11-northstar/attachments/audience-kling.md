# 可灵 Kling AI：用户画像与产品价值

[官网](https://kling.ai/) · 资料核查截至2026-09-10。群体占比均未取得，不由套餐、热榜或有限样本估算。

可灵支持参考图、角色元素和动作要求下的视频生成，以及延长、音画处理和资产管理。普通用户报告过人物、动作或声音不符；官方精选则展示广告和影视采用。这些记录的选择方式不同，尚不足以估计总体交付能力和职业用户占比。

## 用户、供给与付款角色

| 角色 | 当前分析 |
| --- | --- |
| 消费与使用 | 制作个人参考视频、叙事/动画镜头以及尝试效果的人；职业不能由发帖内容推定。 |

## 平台提供什么，解决到哪里

### 1. 每镜重新生成导致人物与道具漂移

适用画像：用个人参考图制作片段的人、对人物、动作和声音有具体要求的镜头制作人。[^kling-1][^kling-3]

| 字段 | 对应关系 |
| --- | --- |
| 平台提供 | Element Library，多视角参考和元素调用 |
| 内容形态 | 个人角色/道具资产、参考素材、生成片段 |
| 起作用的方式 | 保存参考后在新镜头中引用，减少重复描述。 |
| 已观察结果 | 官方能力可确认；普通用户仍报告多人或服装错配，另有用户肯定常规真人输入。 |
| 解决程度 | 能力存在与相反效果自述 |
| 仍未解决或未证明 | 多参考支持是输入能力，不是任意多人镜头一致性保证；没有统一成功率。 |

## 相反证据与未决问题

- 元素一致性是官方重点能力，具体用户仍报告人物混合或多余角色；支持输入数量不是正确输出保证。
- 同一评价认可真人效果而否定卡通口型，不能概括所有输入。
- 付费年包可能伴随持续使用，也可能很少使用；不能将订阅周期视作留存。

- 6个可区分任务账号观察；镜头任务5点集中于Trustpilot自选评论且任务各异，仍不足职业/总体画像。
- 官方精选案例的完整成本、失败数与客户验收，普通用户职业/数量/份额、团队续费和API实际采用未知。

## 后续最有价值的证据

- 补普通创作者从分镜到可采用镜头的原始过程，保留失败、外部剪辑与完成后下一项目。
- 对5种任务继续分别取样，补正向普通用户而非扩大官方精选；找团队/API采购者的真实使用链。
